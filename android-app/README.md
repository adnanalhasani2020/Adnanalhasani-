# تطبيق المستشفى الأصلي — Android

هذه وحدة Android مستقلة باستخدام Kotlin وJetpack Compose، وليست صفحة ويب داخل WebView.

## الشاشات الأولية
- استقبال: نموذج تسجيل مريض واختيار القسم/العيادة وسبب الزيارة.
- قائمة المرضى: اختيار المريض لفتح تفاصيل الزيارة.
- الطبيب: ملف مريض وأزرار التشخيص والفحوصات والأدوية والسجل السابق وموعد المراجعة.
- نوافذ Compose أصلية للحوار والإدخال، واتجاه RTL.

## الحالة الحالية — غير مكتمل
هذه دفعة تأسيسية للواجهات فقط. البيانات الظاهرة تجريبية ومحلية داخل الذاكرة، ولا تُحفظ في قاعدة بيانات، ولا تتصل حاليًا بواجهة Hospital API. لا تستخدمها لسجلات مرضى حقيقية.

## العمل المتبقي قبل اعتبارها جاهزة
1. تنفيذ طبقة اتصال آمنة مع Hospital API وتكوين عنوان الخادم والمصادقة.
2. توصيل تسجيل المرضى والفواتير والمدفوعات إلى نقاط API الحالية.
3. إنشاء قائمة انتظار للطبيب مفلترة بحسب الطبيب والقسم وربط المريض بالزيارة المفتوحة.
4. ربط التشخيص والفحوصات والوصفات وموعد المراجعة بقاعدة البيانات وسجل التدقيق.
5. إضافة استعلام موحد للتاريخ الطبي السابق مع تحقق صلاحيات الوصول.
6. إضافة Gradle wrapper وتشغيل بناء Android والاختبارات على بيئة CI، ثم إصلاح أي أخطاء بناء.
7. مراجعة أمنية واختبارات تدفق كاملة باستخدام بيانات اصطناعية قبل أي استخدام واقعي.

## البناء
افتح مجلد android-app في Android Studio بعد تثبيت Android SDK المناسب. لم يتم تأكيد نجاح البناء لهذه الدفعة بعد، إذ لم تتوفر بيئة بناء Android ضمن هذه الخطوة.
