# تطبيق حسابات المستودع — نسخة أولية

هذا تطبيق Android عربي مستقل عن نظام المستشفى. يحتاج خادم API وقاعدة بيانات مشتركة قبل تسجيل الدخول. البناء الآلي ينتج APK تجريبياً (debug) وليس إصداراً موقعاً للنشر العام.

## البناء
بعد دفع التغييرات إلى الفرع `mobile-accounting-app`، افتح GitHub Actions واختر تشغيل Build Android Accounting APK. عند نجاحه نزّل artifact باسم `mobile-accounting-debug-apk`.

## تنبيه
هذه النسخة الأولية ليست دفتر أستاذ مزدوج القيد ولا تتصل ببنك أو محفظة، ولا ينبغي استخدامها للإقفال المالي أو الإنتاج قبل استكمال API، واختبارات الأمان والمحاسبة، والنسخ الاحتياطي.
