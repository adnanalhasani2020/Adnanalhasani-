# تطبيق حسابات المستودع — نسخة Android أولية

## الشاشات المضافة
- تسجيل الدخول
- لوحة التحكم والملخص
- الحسابات والأرصدة
- إضافة حساب
- تسجيل حركة دخل أو مصروف
- سجل الحركات
- قائمة الفواتير وإضافة فاتورة
- قائمة الدفعات وتسجيل دفعة
- التقارير المالية المختصرة
- إعدادات عنوان الخادم وتسجيل الخروج

## API
يحتوي الخادم على مسارات الحسابات والحركات والفواتير والدفعات والملخص. قاعدة PostgreSQL المشتركة تُنشر عبر Docker Compose. عيّن كلمات مرور ومفاتيح قوية، وضع الخادم خلف HTTPS، ولا تعرض منفذ PostgreSQL للإنترنت.

## بناء APK
فرع `mobile-accounting-app` يشغّل GitHub Actions لبناء APK تجريبي. افتح Actions واختر تشغيل Build Android Accounting APK، ثم نزّل artifact `mobile-accounting-debug-apk` عند نجاح التشغيل.

## حدود النسخة
هذه نسخة أولية وليست نظاماً محاسبياً مكتملاً أو مدققاً. الدفعات المسجلة لا تثبت انتقال الأموال، ولا يوجد حالياً دفتر أستاذ مزدوج القيد، إدارة صلاحيات متعددة المستويات، تصدير PDF/Excel، أو ربط فعلي مع النظام المالي الأصلي. لا تستخدمها للإقفال المحاسبي أو بيانات إنتاجية قبل مراجعة مختص واختبارات أمنية ونسخ احتياطي.
