# متجري — تطبيق Android تجاري

واجهة Android أصلية باستخدام Kotlin وJetpack Compose، باللغة العربية واتجاه RTL.

## الشاشات الحالية
- الرئيسية: ملخص المبيعات، مؤشرات سريعة، تنبيهات المخزون وآخر الفواتير.
- المبيعات: قائمة فواتير تجريبية وزر بدء فاتورة.
- المخزون: قائمة منتجات قابلة للبحث وتنبيهات الكميات المنخفضة.
- المزيد: نقاط دخول أولية للعملاء والمديونيات والمشتريات والتقارير والمصروفات والإعدادات.

## تشغيل التطبيق
من جذر المستودع:
`gradle -p android-commercial assembleDebug`

## ملاحظة مهمة
هذه مرحلة واجهات أولية؛ الأرقام والمنتجات المعروضة بيانات تجريبية. أزرار إنشاء الفاتورة وإضافة المنتج لا تحفظ بيانات بعد. لم يتم ربط التطبيق بعد بقاعدة بيانات أو API أو نظام تسجيل دخول.
