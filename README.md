## ما هو البرنامج اليوم؟

الموجود حالياً هو **نواة Python خلفية** مع تطبيقات مجال وتخزين SQLite وترحيلات واختبارات. تشمل القدرات المنفذة مسارات للهوية والحسابات، والأنشطة والعضويات، والمنتجات والعروض والبيع، وقراءة المخزون، والفواتير والمدفوعات والالتزامات والقروض والحسابات المالية، والتنسيق المالي ضمن نطاق محدد، والمحادثات والرسائل والمرفقات، والتدقيق والأصل والتاريخ.

هذه مكوّنات برمجية داخلية وليست بعد تجربة تطبيق متكاملة للمستخدم النهائي. لا يظهر في المستودع الحالي تنفيذ واجهة Web/Mobile أو API عامة متكاملة أو تكامل مع بنك/محفظة/بوابة دفع. قراءة المخزون لا تعني حجزه أو خصمه، وحفظ Payment لا يثبت انتقال المال، ولا توجد خوارزمية مكتملة لإثبات التوافر أو القرب المحلي.
