## 2. عدد المفاهيم الأساسية
**47 مفهوماً دومينياً + State Record كـModeling Construct.**

تم الانتقال من قائمة مفاهيم مختصرة إلى مفهوم له:
Definition، Purpose، Owner، Change Authority، Consumers، Source of Truth/Derived، Relationships، Cardinality، Lifecycle، States، Temporal Meaning، Provenance، Sensitivity، Invariants، Open Questions.

## 3. عدد العلاقات
**57 علاقة مفاهيمية رئيسية**، مع علاقات فرعية لازمة لتمثيل M:N والسياق.

## 4. المفاهيم التي تم فصلها أو منع دمجها
| الفصل | السبب |
|---|---|
| Person / Access Account / Authenticator / Session | اختلاف الهوية والمصادقة والجلسة |
| Financial Account / Access Account | المال ليس وسيلة وصول |
| Activity / Membership / Role Assignment | السياق والعلاقة والدور ليست هوية |
| Product / Offering / Inventory / Availability / Sale | تعريف عام مقابل عرض وحيازة وتوفر وواقعة بيع |
| Obligation / Debt / Loan | اختلاف النطاق والمعنى المالي |
| Invoice / Transaction / Payment / Settlement / Transfer | وثيقة مقابل حركة وفعل دفع وحسم ونقل |
| Ledger Entry / Balance | مصدر مالي مقابل حالة مشتقة |
| Patient Context / Encounter / Clinical Record / Result / Prescription | طبقات السجل السريري |
| Clinical / Financial Reference | ربط سياقي دون دمج السجل |
| Family Relationship / Delegation / Authorization | العلاقة لا تساوي التفويض |
| Role / Authorization | الدور ليس إذناً تلقائياً |
| Agent / Authority Policy / Action / Approval | الفاعل لا يملك سلطة غير محدودة |
| Provenance / Audit | أصل البيانات ليس سجل التدقيق |
| Device / Pending Operation / Conflict | التشغيل المحلي لا يملك الحقيقة |

## 5. مصادر الحقيقة
المبدأ المركزي: **مالك واحد للحقيقة، والمشتقات تشير إلى المصدر ولا تصبح حقيقة ثانية.**

المصادر الرئيسية:
- Identity: Person/Identifier.
- Access: Access Account/Authenticator/Session.
- Activity: Activity/Membership/Role.
- Commerce: Product/Offering/Sale/Invoice ضمن نطاقها.
- Inventory: Inventory Position.
- Discovery: Availability مشتق.
- Financial Relations: Obligation/Debt/Loan.
- Payments: Transaction/Payment/Settlement/Transfer.
- Finance: Financial Account/Ledger Entry؛ Balance مشتق.
- Health: Patient Context/Encounter/Clinical Record/Result/Prescription.
- Family: Family Relationship.
- Authorization: Delegation/Authorization Grant/Authority Policy.
- Communication: Conversation/Message.
- Instrument: Instrument.
- Governance: Approval/Provenance/Audit.
- Local: Device/Pending/Conflict ضمن وظائفها فقط.

## 6. أهم invariants
1. Person ≠ Access Account ≠ Financial Account.
2. Role/Family Relationship ≠ Authorization.
3. Product ≠ Offering ≠ Inventory ≠ Availability ≠ Sale.
4. Obligation ≠ Debt ≠ Loan.
5. Invoice ≠ Payment ≠ Settlement ≠ Ledger Entry.
6. Balance مشتق.
7. Clinical Record ≠ Commercial Record.
8. Recommendation ≠ Approval ≠ Execution.
9. Provenance ≠ Audit.
10. Offline ≠ Finality.
11. Device/Replica/Pending ≠ Domain Truth.
12. Correction ≠ Deletion.

- استعادة بعد فقد الجهاز.

## 8. نتيجة مراجعة التكرار والتعارض
- Duplicate Concepts: **لا تكرار دلالي جوهري**.
- Multiple Source of Truth: **لا ازدواج مقصود**؛ المشتقات واضحة.
- Hidden M:N: **تم كشفها ومعالجتها بعلاقات ذات معنى**.
- Ambiguous Ownership: **محصورة في سياسات قانونية/محلية مفتوحة، لا في تعريف الحقيقة الأساسية**.
- Missing Lifecycle: **لا فجوة في المفاهيم الأساسية**.
- Missing Temporal Meaning: **تمت إضافة الزمن حيث يغير المعنى**.
- State/Event mixing: **مفصول**.
- Provenance/Audit mixing: **مفصول**.
- Authorization inferred from Role/Family: **ممنوع كمبدأ مفاهيمي**.
- Financial concepts merged incorrectly: **تم الفصل**.
- Clinical/commercial merged: **تم الفصل مع رابط مالي سياقي**.

## 9. القرارات التي أصبحت قابلة للتوصية
- DEC-0002: Primary Account سياقي أو إزالة المفهوم إن لم يثبت معنى مستقلاً.
- DEC-0003: عدم افتراض أن النظام طرف قانوني في العلاقة المالية.
- DEC-0004: Family منفصلة عن Authorization، مع دعم التفويض الجزئي والزمني والقابل للسحب.
- DEC-0005: Instrument عام وأنواع دلالية مستقلة.
- DEC-0006: Authority Policy مالية مستقلة عن Agent.
- DEC-0007: Authority Policy صحية مستقلة عن Agent.
- DEC-0008: Channel Context مستقل.
- DEC-0009: Availability نتيجة Discovery لا خاصية Product.
- DEC-0010: أولوية القطاعات لا تغيّر النواة المفاهيمية.
- DEC-0011: الحالة المالية Offline منفصلة عن finality.
- DEC-0012: مالك Domain للحقيقة يحسم التعارض.
- DEC-0013: Device/Session/Pending منفصلة عن Domain Truth.

## 10. قرارات لا تزال تحتاج صاحب المشروع
- DEC-0001: السوق/الولاية القضائية.
- معنى Primary Account النهائي.
- الدور القانوني للنظام في العلاقات المالية.
- قواعد الأسرة/الوصاية والعمر.
- الأنواع المحلية والقانونية للسندات والقسائم.
- حدود الوكيل المالية والصحية.
- القنوات المدعومة.
- معنى «متاح قريباً».
- أولوية الصحة/التعليم.
- سياسة Offline المالية.
- سياسة recovery وفقد الجهاز.
- قواعد خاصة للتعارضات التي تتأثر بالقانون أو سياسة المجال.

## 11. المخاطر المتبقية
1. الانزلاق من المفهوم إلى جدول/كود قبل اعتماد المعنى.
2. إنشاء «Account» أو «Relationship» عام يعيد دمج مفاهيم مختلفة.
3. اعتبار المشتق حقيقة ثانية.
4. استنتاج الصلاحية من القرابة أو الدور.
5. افتراض finality في Offline.
6. تعديل التاريخ بطريقة تمحو تفسير الماضي.
7. جعل الوكيل مالكاً للقرار.
8. خلط provenance مع audit.
9. تطبيق قانون محلي كقاعدة عالمية.
