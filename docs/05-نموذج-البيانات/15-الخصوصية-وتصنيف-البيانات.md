# الخصوصية وتصنيف البيانات
التصنيف يوجه الجمع والاستخدام والوصول والاحتفاظ والمشاركة.
NIST IR 8496 يشرح data classification كوسم مستمر للحماية على نطاق واسع، وNIST Privacy Framework يدير مخاطر الخصوصية باستمرار.
المفاهيم: sensitivity؛ purpose/context؛ allowed uses؛ retention constraint؛ access basis؛ jurisdiction dependency؛ sharing restrictions.
لا نخلط privacy classification مع authorization.
DEC-0001: لا taxonomy قانونية عالمية قبل تحديد السوق؛ يمكن taxonomy داخلية مرنة مع mapping قانوني لاحق.
