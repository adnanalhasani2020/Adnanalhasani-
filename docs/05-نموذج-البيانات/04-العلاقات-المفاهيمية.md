# العلاقات المفاهيمية
Person ↔ Access Account؛ Person ↔ Membership ↔ Activity؛ Membership ↔ Role؛ Product → Offering → Sale؛ Offering ↔ Inventory؛ Availability ← Inventory/Location/Time/Rules؛ Invoice → Obligation/Financial Effect؛ Payment → Settlement → Ledger Effect؛ Debt ↔ Parties ↔ Obligations؛ Person → Patient Context → Encounter → Clinical Record؛ Family Relationship → Delegation → Authorization؛ Agent → Action → Target Domain؛ Source Entity → Provenance Activity → Derived Entity.

العلاقة لا تنقل ملكية الحقيقة. العلاقات الزمنية تحمل فترة وحالة عندما يلزم. لا تثبت cardinality نهائية قبل السيناريوهات.
