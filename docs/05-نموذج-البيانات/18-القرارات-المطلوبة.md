# القرارات المطلوبة
| DEC | التوصية الآن | الثقة | المفتوح |
| 0001 | **اليمن كسوق مرجعي أول — DECIDED / RESOLVED** | — | لا يوجد سؤال سوق/ولاية مفتوح لهذا القرار؛ أثره على المتطلبات وSPECs يحتاج مراجعة موثقة |
| 0002 | **الخيار الثاني — تجميع منطقي غير مالك — DECIDED / RESOLVED** | — | لا يوجد ambiguity بعد مطابقة الخيار الثاني حرفياً |
| 0003 | **الخيار 2 — DECIDED / RESOLVED** | — | التفاصيل القانونية والتنظيمية والاختصاصات لاحقة |
| 0004 | **تفويض عائلي واضح ومحدود بالصلاحيات — DECIDED / RESOLVED** | — | لا تُستنتج تفاصيل قانونية أو عمرية؛ قواعد الأهلية التفصيلية لاحقة |
| 0005 | Instrument عام وأنواع مستقلة | عالية بنيوياً | الأنواع المحلية |
| 0006 | **User-configured Agent Authority — DECIDED / RESOLVED** | — | لا تنفيذ للكود؛ القيود المالية والاعتمادية باقية |
| 0007 | **User Configuration ضمن قيود السلطة — DECIDED / RESOLVED** | — | التفاصيل الدقيقة للحدود والاستقلالية تحتاج مواصفات/بحث لاحق |
| 0008 | Channel Context مستقل | عالية | قائمة القنوات |
| 0009 | Availability نتيجة Discovery | عالية | تعريف القرب |
| 0010 | **التجارة والخدمات اليومية أولوية أولى — DECIDED / RESOLVED** | — | لا توجد تفاصيل تنفيذية معتمدة؛ الأثر يقتصر على أولوية المراحل والموارد والـMVP/الإصدارات الأولى |
| 0011 | Offline financial state منفصل عن finality | عالية | السياسة المالية |
| 0012 | Owner Domain يحسم التعارض | عالية | الاستثناءات |
| 0013 | Device/session/pending منفصلة عن Domain Truth | عالية | recovery policy |

DEC-0001 حُسم: **اليمن هو الدولة/السوق المرجعي الأول**. DEC-0010 حُسم: **التجارة والخدمات اليومية هي الأولوية الأولى**، مع بقاء الصحة والتعليم والمال ضمن النطاق العام. لا يعني ذلك حسم تفاصيل تنفيذية أو حصر النظام جغرافياً، ولا يحسم أي DEC آخر تلقائياً. أي أثر على المتطلبات أو SPECs يتطلب مراجعة أثر موثقة قبل التنفيذ.
