# الهوية والحسابات
Person → Identity/Identifiers → Access Account → Authenticator/Session. وبشكل مستقل Person → Financial Account.
NIST SP 800-63-4 النهائي في يوليو 2025 يفصل identity proofing وauthentication وfederation. W3C VC 2.0 في مايو 2025 يوضح أن credential ليست Authorization framework كاملة.
DEC-0002: لا Primary Account عام دون معنى مستقل قابل للاختبار؛ يبقى سياقياً أو يُزال. الثقة عالية مفاهيمياً، والقرار النهائي للمالك.
المفاهيم الحساسة: Person، Identifier، Access Account، Authenticator، Session، Financial Account.

## تعميق دفعة 1

Person هو الحقيقة الدائمة للشخص/الجهة؛ Access Account هو سياق وصول وليس هوية.

- Person يمكن أن يرتبط بعدة Access Accounts عند اختلاف سياقات الوصول.
- Access Account لا ينتقل بين الأشخاص كعملية عادية.
- Identifier يعرّف/يشير إلى Person؛ Authenticator يثبت حيازة/سيطرة للمصادقة.
- Authentication لا تمنح Authorization تلقائياً.
- Authorization لا تغير Identity.
- Financial Account مستقل تماماً عن Access Account.

| المفهوم | الحالات الأساسية | الأثر |
|---|---|---|
| Person | active / inactive / corrected | لا ينشئ أو يلغي Access Account تلقائياً |
| Identifier | active / replaced / expired / revoked | انتهاء Identifier لا يمحو Person |
| Access Account | active / suspended / expired / revoked | يمنع/يحد الوصول فقط |
| Authenticator | active / lost / revoked / expired / replaced | يوقف وسيلة المصادقة المتأثرة |
| Session | active / terminated / expired | ينهي جلسة الوصول فقط |

identity correction وidentifier replacement وaccess suspension وauthenticator revocation وsession termination تغييرات زمنية؛ التصحيح لا يساوي حذفاً. لا توجد هنا سياسة محلية للأهلية أو الهوية القانونية؛ ذلك يبقى مفتوحاً.
