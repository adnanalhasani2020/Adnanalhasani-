## تعميق الدفعة 5 — Offline / Multi-Device / History / Privacy

هذه الدفعة تعمق المعنى الدوميني دون إضافة مفهوم دوميني مستقل جديد.

القواعد:
- Offline Operation ≠ Domain Finality.
- Device ≠ Source of Truth.
- Pending Operation ≠ Domain Truth.
- Conflict ≠ Source of Truth ثالث.
- Domain History ≠ Provenance ≠ Audit Record.
- Correction ≠ Delete History.
- Authorization ≠ Purpose/Context of Access؛ وجود السلطة لا يثبت أن استخدام البيانات مشروع لغرض محدد.
- لا يُفترض Version Entity مستقلاً ما لم تثبت حاجة دومينية مستقلة.

تصنيف العمليات بحسب النهائية، لا بحسب التقنية:
A. يمكن إنشاؤها Offline ثم تبقى Pending.
B. يمكن تنفيذها Offline لكن لا تصبح Final إلا بعد تحقق Owner Domain.
C. تحتاج Online/Authority confirmation قبل اعتبارها نهائية.
D. تعتمد على المجال أو DEC مفتوح.

تصنيف الحساسية مبدأ مشترك، لا مخطط تقني. الحد الأدنى المفاهيمي:
Public / Internal / Sensitive / Highly Sensitive-Restricted، مع ترك التسمية النهائية والتفاصيل القانونية لـDEC-0001 والاختصاص والسياق.

الاحتفاظ والحذف:
- لكل Domain Owner تحديد الاحتفاظ المناسب للسياق.
- انتهاء الاحتفاظ لا يعني دائماً إمكان الإزالة الفعلية.
- التصحيح، إزالة الوصول، الإخفاء/التعطيل، والحذف التشغيلي أو الفعلي مفاهيم مختلفة.
- السجلات التي يجب أن تبقى لأسباب صحية أو مالية أو تدقيقية لا تُمحى لمجرد حذف Access Account أو Device أو Person context.
- لا يقرر هذا القسم قاعدة قانونية عالمية.
