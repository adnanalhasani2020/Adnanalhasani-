# مبادئ النمذجة
1. المعنى أولاً.
2. مالك واحد للحقيقة لكل مفهوم حساس.
3. العلاقات ذات المعنى تحمل سياقاً ومدة وحالة عند الحاجة.
4. الزمن صريح عند الحاجة.
5. الحالة ليست الحدث.
6. Provenance يشرح الأصل والاشتقاق؛ Audit يسجل أفعال التدقيق.
7. المشتقات لا تصبح حقيقة ثانية.
8. Person ≠ Access Account؛ Invoice ≠ Financial Transaction؛ Balance ≠ Ledger؛ Payment ≠ Settlement؛ Family ≠ Authorization؛ Clinical Record ≠ Commercial Record.
9. التطور دون ربط المعنى بتقنية.
10. جمع البيانات الحساسة بقدر الحاجة.
11. التفويض قابل للتدقيق.
12. Offline لا يمنح finality تلقائياً.
13. Agent لا يصبح Domain Owner.
