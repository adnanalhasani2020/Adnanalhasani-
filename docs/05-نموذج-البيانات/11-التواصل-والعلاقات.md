# التواصل والعلاقات
Communication يملك messages وconversations وnotifications وdelivery context.
Message ≠ Transaction؛ Notification ≠ Domain State Change؛ Chat ≠ Permission.
Conversation → Participant Membership → Message → Delivery/Read State.
يمكن للرسالة الإشارة إلى Domain Reference دون نقل ملكية الحقيقة إلى Communication.
لا نضغط العلاقات المالية والأسرية والمهنية والتواصلية في Relationship عام يفقد المعنى.
