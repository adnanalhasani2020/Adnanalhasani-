# الصحة والسجل السريري
Clinical Truth يملكه Health؛ السياق المالي للخدمة يملكه Finance/Commerce.
Person → Patient Context → Encounter → Clinical Record → Result/Report → Prescription، وبالتوازي Service → Charge/Invoice/Financial Context.
FHIR يميز Person/Patient/RelatedPerson/Practitioner/PractitionerRole، ويفصل Invoice/ChargeItem عن السجل السريري. openEHR يفصل Reference Model عن Archetypes/Templates للمحافظة على معنى سريري طويل العمر.
DEC-0007: Agent Health Authority مستقلة عن Patient/Practitioner/Role، مع Action/Recommendation/Execution/Approval. الثقة عالية بنيوياً؛ حدود الأفعال تبقى قراراً وقانوناً محلياً.
