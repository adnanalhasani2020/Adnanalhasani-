# منهج النمذجة
التوصية: Conceptual Domain Modeling متعدد الطبقات، يقوده المعنى والملكية الدلالية ثم العلاقات والحالات والزمن ثم القيود.
الطبقات: Identity؛ Domain Context؛ Relationship؛ State؛ History/Provenance؛ Derived.
لكل مفهوم: تعريف، مالك، نطاق، علاقات، دورة حياة، زمن، حساسية، مصدر حقيقة/مشتق، وأسئلة مفتوحة.
السبب: النظام متعدد المجالات وطويل العمر. مراجعة Schema Evolution الحديثة تؤكد أن تغير المخطط جزء من دورة الحياة، وopenEHR يقدم فصلاً قوياً بين البنية المستقرة والمحتوى الدلالي.
المصادر: NIST SP 800-63-4 (2025)؛ W3C VC 2.0 (2025)؛ HL7 FHIR R5؛ openEHR؛ IFRS 2025؛ ISO/IEC 11179-34/35؛ NIST Privacy Framework؛ W3C PROV؛ أبحاث Schema Evolution 2024 وLiving Databases 2026 وLocal-First/CRDT 2025.
