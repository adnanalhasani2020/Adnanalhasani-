# المنتجات والخدمات والمخزون والتوفر
Product ≠ Offering ≠ Inventory ≠ Availability ≠ Sale.
Product هو الهوية العامة؛ Offering عرض في نشاط؛ Inventory Position حالة مخزون؛ Availability نتيجة اكتشاف زمانية/مكانية؛ Sale التزام تجاري.
DEC-0009: التوصية أن متاح قريباً نتيجة Discovery متعددة العوامل لا خاصية Product. الثقة عالية مفاهيمياً.
DEC-0012: عند تعارض نسخة محلية مع المخزون تبقى الحقيقة عند Inventory Owner ويحفظ التعارض.
لا يحول trade-item identifier إلى Inventory أو Availability.
