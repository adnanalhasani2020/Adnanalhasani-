التاريخ: 2026-10-07

## CHG-0002
التاريخ: 2026-10-07
تم توسيع التأسيس ليشمل حالات المعرفة ومصدر الحقيقة وبيانات الوثائق وسجل الرفض والافتراضات والحدود والبوابات والتتبع.

التاريخ: 2026-10-07
تم تنقيح حوكمة التأسيس وإغلاق المرحلة رسمياً ضمن نطاقها فقط.

## CHG-0004 — تنفيذ مرحلة فهم المجال
التاريخ: 2026-10-07
تم تنفيذ مرحلة فهم المجال في docs/01-المتطلبات دون فتح البحث التقني أو المعمارية أو التنفيذ.

## CHG-0005 — تنقيح فهم المجال قبل الإغلاق
التاريخ: 2026-10-07
النطاق: تنقيح محدود داخل مرحلة فهم المجال فقط، بناءً على مراجعة Commit edc41e5b831e2c5998e7efa8069c42b88fc99655.

التغييرات:
1. فصل المستخدم والهوية الرئيسية ووسيلة الوصول/الحساب المرتبط بالوصول والحساب المالي وعلاقة النشاط والجلسة، مع إبقاء معنى Primary Account سؤالاً مفتوحاً.
2. إضافة قاعدة السلع والخدمات العامة، وعرض النشاط، ومخزون النشاط، وموقع المخزون، والتوفر.
3. توضيح أن الشخص الواحد قد يعمل في أنشطة متعددة بهوية بشرية واحدة وعلاقات أدوار مختلفة.
4. إضافة علاقات User ↔ User للقروض والديون والالتزامات والسداد.
5. إضافة السند/القسيمة كمفهوم غير محسوم وتسجيل الحاجة إلى بحث/قرار.
6. توسيع الصحة لتشمل الخدمات المجانية والمدفوعة والمتابعة والتذكيرات والتنبيهات والتواصل والعلاقة المالية دون دمج السياقات.
7. توضيح أن طريقة بدء البيع ليست البيع نفسه، مع تسجيل قنوات البيع كطرق بدء فقط.
8. تصحيح حالة بوابة فهم المجال إلى: منفذة + مراجعة داخلية مكتملة + بانتظار الإغلاق البشري.

لم يتغير نطاق المرحلة. لا كود، لا SQL، لا قاعدة بيانات، لا API، لا UI، لا معمارية، لا اختيار تقنية، لا مزود AI، ولا مزود دفع.
