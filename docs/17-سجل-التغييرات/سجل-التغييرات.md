# سجل التغييرات

**الحالة:** قرار

## CHG-0001
التاريخ: 2026-10-07
تم إنشاء طبقة التأسيس وحوكمة المعرفة لأن المشروع يحتاج ذاكرة تشغيلية قابلة للتتبع.
الطالب: صاحب المشروع.
الأثر البرمجي: لا يوجد؛ هذه مرحلة وثائق فقط.

## CHG-0002
التاريخ: 2026-10-07
تم توسيع التأسيس ليشمل حالات المعرفة ومصدر الحقيقة وبيانات الوثائق وسجل الرفض والافتراضات والحدود والبوابات والتتبع.
الطالب: صاحب المشروع عبر التعديل الرسمي.
الأثر: مراجعة الاتساق قبل إغلاق المرحلة.

## CHG-0003 — تنقيح وإغلاق مرحلة التأسيس
التاريخ: 2026-10-07
تم تنقيح حوكمة التأسيس وإغلاق المرحلة رسمياً ضمن نطاقها فقط.
النتيجة: مرحلة التأسيس مكتملة ومغلقة؛ مرحلة فهم المجال بقيت مغلقة.

## CHG-0004 — تنفيذ مرحلة فهم المجال
التاريخ: 2026-10-07
تم تنفيذ مرحلة فهم المجال في docs/01-المتطلبات دون فتح البحث التقني أو المعمارية أو التنفيذ.

المنجز:
1. خريطة المجال.
2. خريطة الكيانات والعلاقات.
3. قاموس المجال.
4. خريطة العمليات.
5. 20 سيناريوً مرجعياً.
6. حالات الفشل والاستثناءات.
7. الأدوار والمسؤوليات.
8. 28 سؤالاً مفتوحاً.
9. المتطلبات المستخلصة مبدئياً.
10. التعارضات ونقاط التوتر.

تم تحديث الافتراضات والحدود والفهرس وسجل الطلبات والإنجازات. لا يتضمن التغيير كوداً أو قاعدة بيانات أو SQL أو اختيار تقنية.

## قاعدة هذه المرحلة
أي معلومة جديدة لا تغير قراراً معتمداً تلقائياً؛ وإذا ظهرت ضرورة تعديل تأسيسي فتفتح مراجعة موثقة وفق الحوكمة.
