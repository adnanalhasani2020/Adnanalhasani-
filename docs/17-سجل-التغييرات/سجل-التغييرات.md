# سجل التغييرات

**الحالة:** قرار

## CHG-0001
التاريخ: 2026-10-07
تم إنشاء طبقة التأسيس وحوكمة المعرفة لأن المشروع يحتاج ذاكرة تشغيلية قابلة للتتبع.
الطالب: صاحب المشروع.
الأثر البرمجي: لا يوجد؛ هذه مرحلة وثائق فقط.

## CHG-0002
التاريخ: 2026-10-07
تم توسيع التأسيس ليشمل حالات المعرفة ومصدر الحقيقة وبيانات الوثائق وسجل الرفض والافتراضات والحدود والبوابات والتتبع.
الطالب: صاحب المشروع عبر التعديل الرسمي.
الأثر: مراجعة الاتساق قبل إغلاق المرحلة.

## CHG-0003 — تنقيح وإغلاق مرحلة التأسيس
التاريخ: 2026-10-07
تم تنقيح حوكمة التأسيس وإغلاق المرحلة رسمياً ضمن نطاقها فقط.

التعديلات:
1. توضيح نطاق معيار Metadata والتمييز بين وثائق التأسيس التاريخية والوثائق التشغيلية الجديدة.
2. منع تغيير قرار معتمد تلقائياً بسبب دليل أو بحث جديد، مع إلزام فتح مراجعة موثقة.
3. فصل حالات منفذ ومراجع ومعتمد.
4. إضافة تصنيف البيانات وحوكمتها كموضوع بحث لاحق دون اعتماد تصنيف نهائي.
5. إضافة REVIEW إلى سلسلة التتبع عند انطباقها، مع توضيح أنها ليست اعتماداً نهائياً بالضرورة.

النطاق: لا تغيير في نطاق المشروع ولا فتح لمرحلة جديدة.
الوثائق المتأثرة: وثائق الحوكمة، بوابات المراحل، سجل الطلبات، الإنجازات، منهج البحث، وسجل التغييرات والفهرس.
التحقق: مراجعة اتساق نهائية ضمن نطاق التأسيس.
النتيجة: مرحلة التأسيس مكتملة ومغلقة؛ فهم المجال بقي مغلقاً.

## قالب
المعرف، التاريخ، ما تغير، لماذا، من طلبه، القرار السابق، القرار الجديد، الوثائق المتأثرة، الأثر البرمجي المتوقع، والحاجة إلى إعادة الاختبار.
