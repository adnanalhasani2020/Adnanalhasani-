# TEST-0004 — Security, Boundaries, Adversarial & Invariant Verification

**Baseline:** `04fe8b8c5efc5cd9577a6666c0fbe6b1ed82c780`  
**النطاق:** Security boundaries + logical boundaries + adversarial inputs + invariants + ownership isolation

## الهدف
اختبار الحدود الأمنية والمنطقية والحالات العدائية وinvariants ومنع خلط ملكية البيانات بين المجالات، دون إضافة Architecture أو Domain Concepts جديدة.

## التنفيذ
- **43 اختباراً جديداً** في `tests/test_stage8_batch4.py`.
- الاختبارات السابقة لم تُعدل.
- لا Policy Engine، ولا Workflow Engine، ولا Registry، ولا Reconciliation Engine، ولا Financial Orchestration.
- لا Primary Account ولا Actor ولا Permission Role ولا Bank Account/Wallet/Currency ولا Health Concepts جديدة.
- GAP-0001 وGAP-0003 اختُبرا كسلوك حالي ولم تتم معالجتهما.

## محاور التغطية
1. Identity / Access: Person, Identifier, AccessAccount, Session, FinancialAccount، وتعدد Person دون اختراع Primary Account.
2. Activity / Membership / Role: الفصل بين Activity/Organization/Membership/RoleAssignment، مع تثبيت GAP-0002.
3. Commerce: Product/Offering/InventoryPosition/Availability/Sale/Invoice، transitions غير الصالحة، cancellation/history، duplicate boundary.
4. Finance: Invoice/Obligation/Payment/Settlement/FinancialTransaction/LedgerEntry/Balance، اشتقاق Balance، offline boundary، amounts عدائية، replay.
5. Health: Person/PatientContext/Encounter/ClinicalRecord/ResultReport/Prescription، الفصل عن Finance، Family، Agent، Offline، correction/replay.
6. Family / Authorization: FamilyRelationship/Delegation/AuthorizationGrant/RoleAssignment.
7. Agent / Approval / Audit: Agent/AgentAction/Approval/Execution/Provenance/Audit، مع GAP-0001 وGAP-0003.
8. Offline: Device/PendingOperation/Conflict/StateRecord، وعدم منح finality أو domain truth.
9. Cross-domain invariants: اتجاهات الملكية وعدم ظهور Concepts ممنوعة.

## النتائج المقصودة
- Structural invalid references تُرفض حيث يفرضها runtime.
- Sale completion قبل confirmation مرفوض.
- Balance يبقى derived من LedgerEntry.
- Pending/Conflict لا تصبح Financial Finality أو Clinical Truth.
- Cancellation/reversal/correction لا تمحو المراجع الأصلية.
- Inventory/Availability لا تصبح Source of Truth للـSale.
- Family Relationship لا تنشئ Authorization تلقائياً.
- Approval لا تفرض Execution حالياً؛ هذا GAP-0001.
- AuthorizationGrant لا تربط AgentAction تنفيذياً؛ هذا GAP-0003.
- RoleAssignment قد يقبل UUID غير مرتبط بـMembership؛ هذا GAP-0002.
- Duplicate detection موجود كحد مساعد، وليس replay/idempotency engine.
