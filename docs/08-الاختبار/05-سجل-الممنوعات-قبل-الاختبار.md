# سجل ما هو ممنوع حسمه قبل الاختبار

**الحالة:** مفتوح — حوكمة Stage 8

قبل تنفيذ دفعات الاختبار، لا يجوز حسم الآتي ضمنياً:

1. DEC-0001..DEC-0013 أو أي جزء منها.
2. قاعدة قانونية أو تنظيمية أو سوقية غير مثبتة.
3. معنى مالي أو صحي جديد غير موجود في REQ/SPEC.
4. Finality مالية أو صحية ناتجة فقط عن نجاح اختبار تقني.
5. سلطة Agent مستقلة أو Autonomous Authority.
6. نتيجة تعارض Offline/Device/Conflict كحقيقة نهائية دون Owner Domain.
7. Provider/API/UI/DB/Framework كخيار ملزم للمجال.
8. معيار قبول جديد يغيّر معنى SPEC دون مراجعة حوكمية.
9. Concept أو Relationship جديد لتجاوز فشل اختبار.
10. تعديل Stage 3–7 لمعالجة نتيجة اختبار دون مسار تغيير صريح.

## قاعدة التعامل مع الفشل
إذا كشف الاختبار فجوة:
- تُسجل كـFAIL أو BLOCKED أو Gap.
- يُحدد أثرها ونطاقها.
- لا تُعالج بإضافة قرار ضمني.
- يُرفع القرار إلى المرحلة/السجل المناسب عند الحاجة.
