# مراجعة مركزية للمصطلحات

| المصطلح | تعريف بحثي | لا يساوي |
|---|---|---|
| Identity | تمثيل/إثبات من هو الشخص أو الكيان في سياق | authentication/account |
| Authentication | التحقق من ادعاء الهوية | authorization |
| Authorization | منح صلاحية محددة | identity |
| Account | إطار/سجل علاقة أو وصول بحسب المجال | identity/financial account |
| Financial account | سياق مالي للرصيد/الحركات/الالتزامات | user/account العام |
| Product/Trade item | سلعة/خدمة معرفة للتسعير/الطلب/الفوترة | inventory/availability |
| Offering | عرض نشاط لمنتج/خدمة بشروط محلية | global product |
| Inventory | كميات/مواضع/حالة مخزون | availability |
| Availability | نتيجة قابلية الإتاحة/الوعد في سياق زمني ومكاني | inventory |
| Invoice | مستند مطالبة/توثيق توريد بحسب النظام | payment |
| Credit note | تعديل/خفض لفاتورة سابقة في أطر تستخدمه | voucher/receipt |
| Payment | فعل/تعليمات دفع قيمة | settlement |
| Settlement | إتمام/حسم الالتزام وفق قواعد النظام | payment initiation |
| Debt | التزام مالي مستحق | every obligation |
| Loan | علاقة إقراض وتمويل | every debt |
| Obligation | التزام أوسع، ليس بالضرورة مالياً | debt |
| Provenance | أصل/سياق إنشاء أو تعديل معلومة | audit event |
| AuditEvent | سجل حدث قابل للتدقيق | provenance |
| CDS | دعم قرار سريري | diagnosis |
| Agent | فاعل ينفذ ضمن تفويض/صلاحية | principal/user |
| Voucher | أداة حق/استرداد محددة حسب النظام القانوني | coupon/receipt/credit note |
| Initiation channel | طريقة بدء/تفاعل مع العملية | نوع العملية |

هذه المراجعة توحّد اللغة فقط ولا تعتمد نموذج بيانات أو بنية تقنية.
