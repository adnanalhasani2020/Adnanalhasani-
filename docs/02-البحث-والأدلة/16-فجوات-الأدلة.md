# فجوات الأدلة

1. الدولة/السوق المستهدف غير محدد.
2. لا يوجد قرار حول معنى Primary Account.
3. لا يوجد قرار حول ملكية/حوكمة catalog العام.
4. لا يوجد قرار حول السند/القسيمة العام.
5. لا يوجد قرار حول ما إذا كان النظام طرفاً في الالتزام المالي.
6. لا يوجد قرار حول حدود العلاقات المالية User ↔ User.
7. لا توجد قواعد محلية للصحة والدفع والبيانات والأطفال.
8. لا توجد سياسة نهائية للموافقة الأبوية.
9. لا توجد سياسة نهائية لمستوى AI/agent autonomy.
10. لا يوجد بحث تقني تفصيلي للمزامنة/التسوية offline، وهذا مؤجل عمداً.
11. لا توجد مقارنة تقنية لاختيار هوية أو قاعدة بيانات أو مزود دفع/AI، وهذا خارج هذه المرحلة.
12. تعريف "متاح قريباً" يحتاج قراراً دلالياً أكثر من حاجته لمصدر خارجي.
