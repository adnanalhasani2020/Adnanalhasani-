# خريطة البحث والأدلة

## نطاق المرحلة
هذه المرحلة تحوّل الأسئلة المفتوحة والمخاطر والافتراضات المهمة إلى معرفة موثقة، مع فصل الدليل عن الاستنتاج والقرار.

## قاعدة الولاية القضائية
مراجعة المستودع حتى 733b9db9ce6a36de25249534e3fb4ae879bad084 لم تجد دولة/سوقاً مستهدفاً محدداً. لذلك:
- الأدلة الدولية والمهنية تستخدم لتثبيت مفاهيم المجال.
- الحكم القانوني المحلي غير محسوم.
- Q-0023 وQ-0025 وموضوع السوق/العملة يبقون قرارات/أسئلة حرجة إلى أن تحدد الولاية القضائية.
- لا يجوز افتراض اليمن أو أي دولة أخرى من موقع المستخدم.

## تصنيف الأسئلة
A = يمكن حسم الجزء المعرفي بالبحث.
B = يمكن تضييق السؤال لكن يبقى قرار المشروع.
C = قرار صاحب المشروع وليس حقيقة بحثية.
D = يعتمد على الولاية القضائية/السوق.
E = يحتاج بحثاً تقنياً لاحقاً.
U = غير محسوم.

## قوة الدليل
A = قانون/لائحة/معيار رسمي قوي جداً أو جهة تنظيمية مختصة مباشرة.
B = مصدر مهني/أكاديمي قوي أو جهة دولية مختصة.
C = دليل جيد محدود النطاق.
D = دليل استكشافي/ثانوي.
U = غير محسوم.

درجة القوة تصف المصدر لا صحة قرار المشروع.

2. الأسرة والأطفال.

4. المال والمدفوعات والديون.

13. العلاقات المالية User ↔ User.

## قواعد عدم التكرار
سجل المصدر مرة واحدة في سجل الأدلة، والدراسة مرة واحدة في سجل الدراسات، ثم استخدم الإحالات E-/RES- في وثائق المجالات.
