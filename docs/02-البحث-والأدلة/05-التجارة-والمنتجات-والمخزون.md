# التجارة والمنتجات والمخزون

## النتائج
- GS1 يعرّف trade item كمنتج أو خدمة يمكن تسعيرها أو طلبها أو إصدار فاتورة بها؛ GTIN معرف عالمي وليس حالة مخزون. E-0006.
- نماذج inventory/availability المهنية تفصل الكمية الموجودة عن الكمية القابلة للبيع/الوعد، وقد تدخل فيها الحجوزات والطلب والمخزون الآمن والتواريخ. E-0007.
- availability ليست خاصية ثابتة للمنتج؛ هي نتيجة مرتبطة بسياق ومكان وزمن وقيود.
- invoice ليست payment. وcredit note مستند لتصحيح/خفض فاتورة سابقة؛ debit note قد يزيد المقابل. E-0008.
- البيع والطلب والفاتورة والإرجاع والإلغاء والاسترداد حالات/عمليات مترابطة لكنها ليست الشيء نفسه.

Q-0008: ضُيّق، لكن نهائية الفاتورة تعتمد على السوق والقانون ونموذج العمل.
