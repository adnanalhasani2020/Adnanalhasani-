# منهج البحث العلمي والتقني

**الحالة:** قرار — **المعرف:** DOC-RES-0001

القرارات المهمة لا تُبنى على رأي الوكيل فقط.

## مصادر الأدلة
الأبحاث المحكمة، المراجعات العلمية، المعايير الرسمية، الوثائق الرسمية للتقنيات، الممارسات الهندسية الموثقة، الاختبارات والقياسات، والمصادر الميدانية الموثوقة عند الحاجة.

## قوة الدليل
- دليل قوي.
- دليل متوسط.
- دليل محدود.
- رأي هندسي.
- فرضية تحتاج اختباراً.

لا تستخدم عبارة «أحدث تقنية» دون التحقق من تاريخ المصدر وحالته.

## الدراسات المطلوبة لاحقاً
SQLite والتخزين المحلي، المزامنة والعمل دون اتصال، الأنظمة الموزعة، الهوية والصلاحيات، أمن البيانات والخصوصية، **تصنيف البيانات وحوكمتها**، المدفوعات والمحاسبة الرقمية، الأنظمة والسجلات الصحية، الذكاء الاصطناعي الوكيلي وذاكرة الوكلاء واستدعاء الأدوات، الذكاء الاصطناعي في الصحة والمسؤول، الشبكات منخفضة الاتصال، والأجهزة محدودة الموارد.

ضمن موضوع **تصنيف البيانات وحوكمتها**، يشمل البحث المستقبلي على الأقل التمييز بين بيانات عامة، شخصية، حساسة، صحية، مالية، هوية، اعتماد وأسرار، تشغيل، وتدقيق. هذه خارطة بحث وليست تصنيفاً نهائياً للبيانات.

التوصية البحثية ليست قراراً تلقائياً؛ القرار يسجل في سجل قرارات مستقل.
