# سجل القرارات المحظورة على التنفيذ — Stage 7

**القاعدة الحاكمة:** الوكيل المنفذ لا يحسم DEC-0001..0013 من تلقاء نفسه.

| DEC | نوع الحظر | عند مواجهته | ما يستمر |
|---|---|---|---|
| DEC-0001 | قانون/ولاية/قطاع | تسجيل Decision-Blocked | البنية الدلالية والحدود غير القانونية |
| DEC-0002 | نموذج حساب | تسجيل الجزء المتعلق بـPrimary Account | Identity/Access/Finance separation |
| DEC-0003 | دور مالي قانوني | إيقاف السلوك الذي يفترض دور النظام | Finance primitives والحدود |
| DEC-0004 | أسرة/وصاية/أهلية | إيقاف قواعد الأهلية التلقائية | Family/Delegation/Authorization separation |
| DEC-0005 | Instrument financial semantics | إيقاف الأثر المالي النوعي | Instrument lifecycle/provenance |
| DEC-0006 | Agent financial authority | منع التنفيذ المالي غير المحسوم | Agent/Policy/Approval/Audit foundations |
| DEC-0007 | Agent health authority | منع الفعل السريري المستقل | Health core وrecommendation/approval boundaries |
| DEC-0008 | Channel scope | عدم قفل قائمة القنوات | Channel abstraction وCommerce boundary |
| DEC-0009 | Discovery semantics | عدم اختراع proximity/availability algorithm | Inventory/Discovery boundaries |
| DEC-0010 | Health/Education priority | عدم افتراض أولوية مرحلية | Context boundaries and reusable foundations |
| DEC-0011 | Offline financial finality | منع أي financial finality offline | Pending/non-final foundations |
| DEC-0012 | Conflict authority | عدم اختيار winner/merge rule | Conflict representation وOwner Domain routing |
| DEC-0013 | Device loss/recovery | عدم افتراض recovery policy | Device/Session/Pending/history foundations |

## سجل الحظر
عند ظهور قرار أثناء التنفيذ، يسجل المنفذ:
1. EXEC ID.
2. REQ/SPEC المتأثرة.
3. DEC ID.
4. القرار الذي لا يمكن افتراضه.
5. الجزء المتوقف فقط.
6. الأجزاء التي تستمر دون القرار.
7. أي اختبار لا يمكن اعتماده حتى صدور القرار.

## ممنوعات خاصة
- لا تحويل DEC إلى default.
- لا إنشاء Concept/Relationship جديد لتجاوز القرار.
- لا نقل Source of Truth إلى implementation layer.
- لا تحويل Device/Pending/Conflict إلى final truth.
- لا تحويل Agent إلى autonomous authority.
- لا تحويل Recommendation إلى Decision أو Prescription.
- لا تحويل Payment إلى Settlement أو Ledger Truth تلقائياً.
- لا تحويل Family Relationship إلى Authorization تلقائياً.

## إعادة الفتح
عند صدور DEC لاحقاً، تُفتح مراجعة أثر موثقة على EXECs المتأثرة، ولا تعدل المواصفات أو التنفيذ بصمت.
