# سجل اعتماد التنفيذ — Stage 7

**القاعدة:** هذا السجل لا يحسم أي DEC؛ يحدد فقط أثرها التنفيذي.

| DEC | ما الذي تمنعه فعلياً | ما يمكن تنفيذه دون حسم | الجزء المشروط |
|---|---|---|---|
| DEC-0001 | قواعد الولاية/السوق القانونية والقطاعية، وبعض قواعد الصحة/الخصوصية/الأسرة/المال | حدود المجالات، الهوية، مصادر الحقيقة، بنية الصلاحيات العامة، اختبارات عدم الادعاء القانوني | قواعد قانونية/قطاعية وتفاصيل الوصول الحساسة |
| DEC-0002 | معنى Primary Account وتجميع الحسابات | Person/Access Account/Financial Account منفصلة، Session، حدود Finance | أي مفهوم/سلوك Primary Account |
| DEC-0003 | الدور القانوني للنظام في العلاقات المالية | Financial Account/Obligation/Ledger/Balance boundaries، وPayment/Settlement separation | إقراض/تحصيل/التزامات قانونية أو دور النظام كطرف مالي |
| DEC-0004 | قواعد الأسرة/الوصاية/الأهلية | Family Relationship، Delegation/Authorization boundaries، lifecycle غير القانوني | قواعد الأهلية والوصاية والصلاحية الأسرية |
| DEC-0005 | أنواع Instrument وأثرها | Instrument boundary، provenance، lifecycle العام، عدم تحويله تلقائياً إلى مالية | الأثر المالي لكل نوع Instrument |
| DEC-0006 | حدود الأفعال المالية للوكيل والموافقة المطلوبة | Agent/Authority Policy/Agent Action/Approval boundaries، attribution/audit | الأفعال المالية المسموحة والاستقلالية |
| DEC-0007 | حدود الأفعال الصحية للوكيل والاستقلالية السريرية | Health core، Agent/Recommendation/Approval boundaries، audit | الأفعال الصحية التي يمكن للوكيل تنفيذها والاستقلالية |
| DEC-0008 | قائمة القنوات التجارية المدعومة | Channel Context boundary، فصل القناة عن Sale/Payment | القنوات النهائية المدعومة وتغطية كل قناة |
| DEC-0009 | تعريف «متاح قريباً» | Inventory truth، Discovery boundary، Availability كـresult | تعريف القرب/الزمن وخوارزمية/معايير الاكتشاف |
| DEC-0010 | أولوية ونطاق الصحة والتعليم | Education context boundary، Health/Finance separation | ترتيب القطاعات والأولوية المرحلية وتفاصيل النطاق |
| DEC-0011 | ما يجوز مالياً دون اتصال | Offline/Pending/Finality boundaries، non-final local operations | قبول/رفض/نهائية العمليات المالية Offline |
| DEC-0012 | صاحب القرار عند تعارض المخزون/الأجهزة | Device/Pending/Conflict abstractions، Owner Domain principle | قاعدة الحسم النهائية وتفاصيل conflict behavior |
| DEC-0013 | أثر فقد الجهاز والعمليات المعلقة | Device/Session/Pending foundations، history/provenance boundaries | recovery semantics النهائية، أثر الفقد على العمليات |

## قاعدة الإيقاف الجزئي
إذا احتاجت خطوة تنفيذية قراراً مفتوحاً، لا تُوقف الدفعة كلها تلقائياً. يُعزل الجزء المتأثر، يسجل كـDecision-Blocked، وتستمر الأجزاء المستقلة.

## قاعدة عدم الحسم
لا يحق للمنفذ تحويل DEC إلى default، configuration ثابتة، schema constraint، API contract، UI rule، provider dependency، أو business rule نهائية.

## حالة السجل
جميع DEC-0001..0013 = **DECIDED / RESOLVED** وفق السجل الرسمي. لا يوجد قرار تنفيذي يحل محلها؛ التنفيذ يجب أن يتبع القرارات المحسومة وREQ/SPEC/EXEC المرتبطة بها.
