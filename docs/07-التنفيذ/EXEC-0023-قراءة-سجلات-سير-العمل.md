# EXEC-0023 — Read persisted Workflow and Workflow Event records

## Evidence of gap
- The relational schema defines `workflows` and `workflow_events`, including namespace, workflow kind/state, version, event sequence, timestamps, and optional detail references.
- No dedicated application query path was found to restore a workflow, list workflows in a namespace, or read its events in sequence order.

## Implemented capability
- Read one persisted workflow by ID.
- List workflows for an explicitly supplied namespace in deterministic order.
- List events for an existing workflow ordered by `event_sequence`.

## Boundary
- Read-only: no state transitions, event appends, workflow finality, authorization, or domain side effects are introduced.
- The implementation does not infer workflow-specific lifecycle rules or change the existing schema.
- Empty namespace results are valid; an unknown workflow is rejected when the caller requests that workflow or its events.

## Tests
`tests/test_stage38_workflow_read_application.py` covers namespace reads, deterministic event order, unknown workflow handling, and required namespace validation.
