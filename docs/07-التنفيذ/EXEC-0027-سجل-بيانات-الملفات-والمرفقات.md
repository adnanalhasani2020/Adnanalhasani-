# EXEC-0027 — سجل بيانات الملفات والمرفقات

## الفجوة التشغيلية
كان مسار التخزين يوفّر قاعدة SQLite والترحيلات، لكن لم يوجد جدول/خدمة تطبيقية مخصصة لتسجيل بيانات الملف واستعادتها. مراجع المحتوى في وظائف التواصل لا تمثل سجل ملف موحدًا ولا تحفظ الحجم أو نوع الوسائط أو checksum.

## التسليم
- جدول `file_attachments` عبر ترحيل إضافي.
- خدمة `FileAttachmentApplication` لإنشاء سجل بيانات وصفية واسترجاعه وسرد السجلات بترتيب حتمي.
- حقول إلزامية: مرجع تخزين opaque، اسم ملف basename، media type، حجم موجب، SHA-256 بصيغة hex صغيرة، بيانات وصفية JSON، ووقت UTC.
- رفض تكرار `storage_ref` ومعرّف المرفق، والحقول غير الصالحة.
- اختبارات استمرار البيانات بعد إغلاق قاعدة البيانات وإعادة فتحها، والتحقق من المدخلات والتكرار والقراءة من سجل مفقود.

## الحدود
- هذا سجل بيانات وصفية وليس مخزن bytes أو محول تخزين.
- لا يجري التطبيق رفعًا أو تنزيلًا أو فحصًا فعليًا لوجود الكائن أو تطابق checksum مع bytes؛ يجب على مستهلك التخزين التحقق من ذلك قبل التسجيل.
- لا يتضمن صلاحيات وصول، أو استنتاج صلاحية من المرجع، أو ربطًا تلقائيًا بكيانات مجال، أو سياسات احتفاظ/حذف غير معتمدة.
- لا ينشئ آثارًا مالية أو تجارية، ولا يغيّر قرارات أو عقودًا رسمية.
