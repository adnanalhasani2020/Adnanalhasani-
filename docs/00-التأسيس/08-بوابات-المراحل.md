# بوابات الانتقال بين المراحل

**الحالة:** قرار — **المعرف:** DOC-GOV-0008

التسلسل: **التأسيس → فهم المجال → البحث والأدلة → المتطلبات → المعمارية → نموذج البيانات → المواصفات → التنفيذ → الاختبار → التقييم → الإصدار**.

## بوابة التأسيس
**الدخول:** طلب تأسيسي واضح.
**المخرجات:** حوكمة المعرفة، الفهرس، السجلات، المبادئ، الحدود، منهج البحث.
**النجاح:** مصدر حقيقة وحالات معرفة وتتبع وسجلات قابلة للاستخدام.
**الحالة:** مفتوحة للتأسيس فقط؛ التنفيذ مغلق.

## البوابات اللاحقة
لكل انتقال لاحق يجب تحديد شروط الدخول والمخرجات وشروط النجاح وقرار اعتماد. فهم المجال يتطلب تعريف الجهات والأدوار والمصطلحات والافتراضات. البحث يتطلب دراسات موثقة. المتطلبات تتطلب قابلية التتبع. المعمارية تتطلب بدائل ومفاضلات وقرارات. نموذج البيانات يتطلب فهم المجال والتدقيق والمزامنة والأمن. المواصفات يجب أن تكون قابلة للتنفيذ. التنفيذ لا يفتح تلقائياً. الاختبار والتقييم والإصدار تحتاج معايير قبول وأدلة نتيجة.

## قاعدة منع القفز
اكتمال الملفات لا يفتح مرحلة. لا ينتقل الوكيل تلقائياً من التأسيس إلى التنفيذ.
