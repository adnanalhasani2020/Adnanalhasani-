# بوابات الانتقال بين المراحل

**الحالة:** قرار — **المعرف:** DOC-GOV-0008

التسلسل: **التأسيس → فهم المجال → البحث والأدلة → المتطلبات → المعمارية → نموذج البيانات → المواصفات → التنفيذ → الاختبار → التقييم → الإصدار**.

## بوابة التأسيس
**الحالة:** **مكتملة ومغلقة.**

إغلاق هذه البوابة لا يعني اعتماد المعمارية أو قاعدة البيانات أو التقنيات، ولا يفتح أي بوابة لاحقة تلقائياً.

## بوابة فهم المجال

**الحالة الحالية: منفذة + مراجعة داخلية مكتملة + بانتظار الإغلاق البشري.**

**المخرجات:** DOM-0001 إلى DOM-0010، مع التنقيح الأخير المسجل في CHG-0005.

شروط الإغلاق المتبقية:
- مراجعة بشرية للأسئلة الحرجة.
- مراجعة التعارضات ونقاط التوتر.
- اعتماد أن المفاهيم غير المحسومة بقيت أسئلة/افتراضات ولم تتحول إلى قرارات.
- اعتماد اتساق السجلات وحالة البوابة.

**لا تُعد البوابة مغلقة حالياً.**

## المرحلة التالية
**البحث والأدلة** هي المرحلة التالية بعد إغلاق فهم المجال، وتبقى مغلقة حتى يصدر أمر صريح وتستوفى شروط البوابة.

لا يبدأ البحث التقني أو المتطلبات النهائية أو المعمارية أو نموذج البيانات أو التنفيذ تلقائياً.

## قاعدة منع القفز
اكتمال الملفات أو المراجعة الداخلية لا يساوي الإغلاق البشري. لا ينتقل الوكيل تلقائياً إلى المرحلة التالية.
