# بوابات الانتقال بين المراحل

**الحالة:** قرار — **المعرف:** DOC-GOV-0008

التسلسل: **التأسيس → فهم المجال → البحث والأدلة → المتطلبات → المعمارية → نموذج البيانات → المواصفات → التنفيذ → الاختبار → التقييم → الإصدار**.

## بوابة التأسيس
**الحالة:** مكتملة ومغلقة.

## بوابة فهم المجال
**الحالة: مغلقة.**

سبب الإغلاق: أمر صاحب المشروع في 2026-10-07 بالانتقال إلى مرحلة البحث والأدلة بعد تنفيذ فهم المجال ومراجعته داخلياً، مع استمرار حفظ الأسئلة غير المحسومة وعدم تحويلها إلى قرارات تقنية.

المخرجات: DOM-0001 إلى DOM-0010 مع CHG-0005.

## بوابة البحث والأدلة
**الحالة الحالية: مفتوحة وقيد التنفيذ.**

المخرجات المخطط لها: RES-0001 وما يتبعها من خريطة البحث، سجل الدراسات، سجل الأدلة، دراسات المجالات، مصفوفة Evidence → Decision، فجوات الأدلة، ونقاط التصحيح.

شروط الإغلاق:
- مراجعة جودة وحداثة ونطاق الأدلة.
- مراجعة الأسئلة التي تحتاج قراراً بشرياً.
- تحديد الولاية القضائية قبل الاستنتاج القانوني المحلي.
- مراجعة التناقضات بين المسارات.
- تثبيت ما أصبح معرفة، وما بقي قراراً/فجوة.
- اعتماد بشري صريح؛ لا يحدث الإغلاق تلقائياً.

## المراحل التالية
المتطلبات النهائية والمعمارية ونموذج البيانات والتنفيذ **مغلقة** ولا تفتح تلقائياً.

لا يبدأ البحث التقني التفصيلي إلا بقدر ما يلزم لفهم خطر مجال، وأي اختيار تقني مؤجل إلى المرحلة المخصصة.
