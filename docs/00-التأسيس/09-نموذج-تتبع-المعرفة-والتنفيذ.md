# نموذج تتبع المعرفة والتنفيذ

**الحالة:** قرار — **المعرف:** DOC-GOV-0009

السلسلة المستهدفة عند انطباق المراحل: **REQ → ADR و/أو RESEARCH → SPEC → IMPLEMENTATION → REVIEW → TEST → ACHIEVEMENT**.

**REVIEW تعني مراجعة العمل وفق معيار مناسب، وليست بالضرورة اعتماداً نهائياً.** وجود REVIEW ليس مطلوباً لكل شيء؛ يستخدم عندما تكون المراجعة منطقية أو مطلوبة، مثل القرارات أو الأعمال الحساسة أو المالية أو الصحية أو الأمنية، أو عندما تنص مواصفة العمل على ذلك.

الطلب يثبت ماذا نريد. البحث يثبت ماذا تعلمنا وقوة الدليل. القرار يثبت لماذا اخترنا. المواصفة تثبت ماذا سنبني. التنفيذ يثبت ماذا بُني. المراجعة تثبت أن العمل خضع لفحص وفق معيار مناسب ونتيجته. الاختبار يثبت هل يحقق معايير الاختبار. الإنجاز يثبت ماذا اكتمل فعلاً.

ليس مطلوباً وجود كل مرحلة لكل طلب، لكن لا يجوز فقد العلاقة عندما تكون المرحلة منطبقة.
