# معيار بيانات الوثائق

**الحالة:** قرار — **المعرف:** DOC-GOV-0004

كل وثيقة تشغيلية جديدة تحتوي على بيانات وصفية موحدة قابلة للبحث الآلي.

## الحقول الإلزامية
- معرف الوثيقة
- العنوان
- النوع
- الحالة
- الإصدار
- تاريخ الإنشاء
- تاريخ آخر تعديل
- المصدر
- الأهمية
- حالة الاعتماد

## حقول التتبع
الوثائق المرتبطة، القرارات المرتبطة، الطلبات المرتبطة، الأبحاث المرتبطة، المواصفات المرتبطة، الاختبارات المرتبطة، والإنجازات المرتبطة.
