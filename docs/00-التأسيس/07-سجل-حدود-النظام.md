# سجل حدود النظام

**الحالة:** قرار — **المعرف:** DOC-GOV-0007

## حدود مؤكدة من البحث
- الحساب ليس الهوية أو الجلسة أو الدين أو الرصيد.
- الشخص لا يحتاج هوية جديدة لكل نشاط.
- المنتج العام ≠ عرض النشاط ≠ المخزون ≠ التوفر.
- الفاتورة ≠ الدفع ≠ التسوية.
- الأسرة/الوالد ≠ ملكية مطلقة لبيانات الطفل.
- الوكيل لا يكتسب صلاحيات إضافية من الذكاء أو الأدوات.
- AI الصحي ≠ تشخيص نهائي أو مسؤولية بشرية.
- offline ≠ final financial settlement.
- voucher ≠ discount/credit/receipt تلقائياً.
- قناة بدء البيع ≠ نوع بيع مستقل.

## خارج النطاق الحالي
- اختيار تقنية هوية أو قاعدة بيانات أو API.
- تصميم المزامنة النهائي.
- مزود دفع أو AI.
- تشخيص طبي مستقل أو وصف دواء آلي.
- تحويل/حفظ أموال فعلي.
- حكم قانوني محلي قبل تحديد الدولة.

## فجوة حرجة
الدولة/السوق المستهدف غير محدد. لذلك لا يجوز اعتماد سياسة امتثال محلية الآن.
