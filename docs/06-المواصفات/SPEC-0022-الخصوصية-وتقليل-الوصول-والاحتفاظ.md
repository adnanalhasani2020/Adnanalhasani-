# SPEC-0022 — الخصوصية وتقليل الوصول والاحتفاظ

## 1. الغرض والنطاق
تحدد هذه المواصفة السلوك الدلالي للخصوصية وتقليل الوصول والاحتفاظ ضمن حدود Authorization والمفاهيم الموجودة.
**Authorization ≠ Privacy.**
لا تنشئ Privacy Policy كـConcept جديد.

## 4. المفاهيم المستخدمة
Authorization Grant، Family Relationship، Delegation، Role Assignment، Purpose/Access Context، Sensitivity Classification، Retention Constraint، Person، Clinical Record، Financial Account، Conversation، Agent Action، Audit Record.
Purpose/Access Context وSensitivity Classification وRetention Constraint لا تتحول هنا إلى Concepts جديدة إن لم تكن كذلك في Stage 5.

## 5. Authorization ≠ Privacy
Authorization تحدد هل الفعل/الوصول مسموح ضمن حدود السلطة.
Privacy تحدد دلالياً تقليل الوصول والاستخدام والاحتفاظ وفق السياق والغرض والحساسية والقيود.
وجود Authorization لا يلغي least privilege، والحاجة إلى الخصوصية لا تنشئ Authorization.

## 6. Least Privilege وتقليل الوصول
- الوصول يقتصر على ما يلزم للغرض والسياق.
- الدور أو العلاقة الأسرية لا تمنح وصولاً أوسع من السلطة.
- لا تُستخدم بيانات مجال لفتح وصول إلى مجال آخر بلا Authorization.
- Agent لا يوسع صلاحية نفسه.
- الإمكانية التقنية للوصول لا تجعل الوصول غير الضروري مقبولاً.
لا تحدد المواصفة آلية تقنية لتطبيق ذلك.

## 7. Family Relationship
**Family Relationship ≠ Authorization.**
العلاقة الأسرية لا تمنح تلقائياً وصولاً شاملاً إلى الصحة أو التعليم أو المال أو الرسائل أو الحساب.
Delegation وAuthorization Grant تبقيان منفصلتين.

## 8. Purpose / Access Context
Purpose/Access Context يقيدان معنى الوصول أو الفعل عند الحاجة.
لا تنشئ المواصفة Purpose taxonomy جديدة ولا Concept مستقلاً.

## 9. Sensitivity والاحتفاظ
الحساسية الأعلى تضيق السلوك المسموح بالوصول والاستخدام وفق Authorization والسياق.
الاحتفاظ يراعي الغرض والحاجة التشغيلية/المجالية والقيود المعتمدة.
انتهاء صلاحية الوصول لا يساوي حذف Domain Truth.
لا مدة احتفاظ رقمية ولا قاعدة قانونية عالمية.

## 10. Failure / Exception
- Authorization موجودة ≠ وصول غير محدود.
- Family Relationship ≠ Authorization.
- Role Assignment ≠ Authorization.
- Audit Record ≠ Authorization.
- Agent capability ≠ Authorization.
- انتهاء Authorization ≠ حذف Domain Truth.
- تقليل الوصول ≠ تغيير مالك الحقيقة.

## 11. History / Provenance / Audit
Privacy لا تملك Domain History.
Audit يسجل أفعال الوصول عند الحاجة لكنه لا يصبح Domain Truth.
Provenance يصف أصل المعلومة أو الفعل.
**Provenance ≠ Audit ≠ Domain Truth.**
Correction لا يساوي حذف التاريخ.

## 12. Offline / Agent
Offline لا يوسع الوصول.
بيانات محلية لا تصبح مباحة خارج Authorization والسياق.
Agent لا يكتسب صلاحية من توفر البيانات على Device.
Pending Operation لا تنشئ حق وصول جديداً.
