# SPEC-0025 — الحدود المالية العابرة للصحة والتعليم

## 1. الغرض والنطاق
تحدد هذه المواصفة الحدود الدلالية بين الصحة والتعليم والحقائق المالية، مع إبقاء كل حقيقة عند Owner Domain الخاص بها.
**Health/Clinical Truth ≠ Finance.**
**Education context ≠ Financial Account.**
لا تنشئ مفهوماً مالياً أو تعليمياً جديداً.

## 4. المفاهيم المستخدمة
Service، Encounter، Patient Context، Clinical Record، Financial Reference، Invoice، Obligation، Payment، Settlement، Financial Account، Financial Transaction، Ledger Entry، Balance، Education context، Activity، Authorization Grant.
لا Concept جديد.

## 5. Health/Finance boundary
Health يملك Patient Context وEncounter وClinical Record وResult/Report وPrescription.
Finance يملك Financial Account وFinancial Transaction وLedger Entry وBalance والاعتراف المالي النهائي.
**Clinical Truth ≠ Financial Truth.**

## 6. Service / Encounter ≠ Invoice / Payment
**Service/Encounter ≠ Invoice.**
**Service/Encounter ≠ Payment.**
قد ينتج عن خدمة أو Encounter رابط أو مرجع مالي، لكن ذلك لا يجعل الحقيقة السريرية فاتورة أو دفعاً.
Invoice تبقى Commerce truth.
Payment/Settlement تبقى Payments truth.
Financial Transaction/Ledger Entry/Balance تبقى Finance truth.

## 7. Financial Reference
Financial Reference رابط سياقي بين حقيقة مجال وخط مالي عند الحاجة.
هو ليس Financial Account ولا Ledger Entry ولا Payment.
وجوده لا ينقل Clinical Truth إلى Finance ولا Financial Truth إلى Health.

## 8. Education/Finance boundary
Education context يصف سياقاً تعليمياً ولا يصبح Financial Account.
الرسوم التعليمية قد ترتبط بـInvoice/Obligation/Payment، لكن:
Education context ≠ Financial Account.
Education context ≠ Ledger Entry.
Payment ≠ educational record.
Invoice ≠ educational context.
Finance يملك الأثر المالي المعترف به.

## 9. Lifecycle / behavior
Health: Service/Encounter → financial reference → financial process → Finance recognition.
Education: education context → financial reference → invoice/obligation/payment → Finance recognition.
الرابط المالي لا يغير Clinical Truth أو السياق التعليمي تلقائياً.

## 10. Failure / Authorization / Offline
Payment failed ≠ Clinical Record failed.
Invoice cancelled ≠ Patient Context cancelled.
Financial recognition delayed ≠ deletion of Health Truth.
Education fee state ≠ education participation state.
الوصول إلى Health/Finance يخضع Authorization والسياق والغرض.
Offline financial operation ≠ Financial Finality.
Agent لا يملك Clinical Truth أو Financial Truth.
Pending Operation لا تنقل الملكية.
