# SPEC-0026 — مصدر الحقيقة والتتبع الدلالي

## 1. الغرض والنطاق
هذه مواصفة Cross-cutting/Semantic Traceability لضبط مطابقة الادعاء أو النتيجة بالمصدر المالك للحقيقة. ليست Domain Specification ولا تملك Domain Truth ولا تنشئ Source of Truth جديداً.
**كل Owner Domain يحتفظ بحقيقته.**
**Derived ≠ Source of Truth.**
**Provenance ≠ Audit ≠ Domain Truth.**

## 3. Dependencies
- Domain Constraint: each Owner Domain remains its own Source of Truth.
- SPEC-0021: Audit/Provenance/History boundaries.
- SPEC-0009: financial truth and derived balance boundary.
- SPEC-0013: communication behavior.
هذه الاعتماديات اللازمة فقط؛ لا يعني الطابع العابر للمجالات اعتماداً على كل SPEC.

## 4. المفاهيم المستخدمة
Source of Truth، Derived، Provenance، Audit Record، Domain History، Financial Account، Obligation، Payment، Settlement، Instrument، Sale، Invoice، Communication، Notification، Agent Action، Clinical Record، Inventory Position، Authorization.
لا Source-of-Truth Concept جديد ولا Domain Owner جديد.

## 5. Source of Truth rule
كل حقيقة مجالّية تُنسب إلى Owner Domain المالك لها.
المواصفة لا تنشئ حقيقة ثانية عندما توجد نتيجة مشتقة أو نسخة تشغيلية.
**Derived ≠ Source of Truth.**
Snapshot/result/reference لا تصبح Owner Domain Truth لمجرد أنها مشتقة أو معروضة.

## 7. Derived behavior
Availability قد تعتمد على Inventory، وBalance على Ledger Entries، وقد ترتبط Invoice/Payment بـFinancial recognition.
في كل حالة المشتق مفيد للتشغيل أو العرض لكنه لا يصبح Owner Domain تلقائياً، وتحديثه لا يعيد تعريف المصدر.

## 8. Provenance / Audit / History
Provenance يربط المعلومة أو الفعل بمصدره/أصله عند الحاجة.
Audit Record يسجل الفعل أو الوصول أو القرار أو التغيير المطلوب للتدقيق.
Domain History تبقى عند Owner Domain.
**Provenance ≠ Audit ≠ Domain History ≠ Domain Truth.**
لا يمنح أي منها Authorization أو ملكية بديلة.

## 9. Agent boundary
**Agent Action ≠ Domain Truth.**
Agent قد ينتج Recommendation أو ينفذ فعلاً مصرحاً به، لكن الحقيقة الناتجة تملكها الجهة الدومينية المستهدفة.
Provenance/Audit يمكن أن يسجلا فعل Agent دون أن يصبحا الحقيقة الدومينية.

## 10. Financial / Communication / Health / Inventory / Education
Financial Account/Obligation/Payment/Settlement/Ledger لا تتبادل الملكية بسبب التتبع.
Balance مشتق من Finance ولا يصبح Owner Domain مستقلاً.
Communication يحمل reference/context ولا يملك الحقيقة الأصلية.
Clinical Record يبقى Health truth.
Inventory Position تبقى Inventory truth.
Education context لا يصبح Financial Account.
Discovery result لا يصبح Inventory truth.

## 11. Failure / Exception
- Derived value stale ≠ source changed بالضرورة.
- Derived ≠ source.
- Provenance ≠ Audit.
- Audit ≠ Domain Truth.
- Conflict ≠ third truth.
- Pending Operation ≠ Domain Truth.
- Agent Action ≠ Domain Truth.
- Reference/link ≠ ownership transfer.

## 12. Authorization / Privacy
التتبع لا يمنح وصولاً.
قراءة Source of Truth أو Derived result تخضع Authorization وPrivacy.
وجود Provenance أو Audit لا يفتح البيانات.
Least Privilege يبقى قائماً.

## 13. Offline / Device
Offline result ≠ Source of Truth.
Device/Pending Operation لا يملكان الحقيقة.
إذا اختلف local/derived state مع Owner Domain، يبقى Owner Domain المصدر الدلالي للحقيقة.
لا Sync/Replication protocol.
