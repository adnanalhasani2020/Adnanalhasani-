# SPEC-0023 — الاستثناءات والإلغاء والإرجاع والتكرار

## 1. الغرض والنطاق
هذه مواصفة Cross-domain للسلوك الاستثنائي، وليست مالكة لحقيقة أي مجال. تحدد الرفض والتكرار والإلغاء والإرجاع/العكس والتعافي دلالياً، بينما يقرر Owner Domain الحالة النهائية.
لا تنشئ Refund أو Retry أو Recovery كـConcepts جديدة.

## 4. المفاهيم المستخدمة
Payment، Sale، Invoice، Obligation، Settlement، Agent Action، Pending Operation، Financial Transaction، Ledger Entry، Authorization، Domain History.
لا Refund Concept، ولا Retry Concept، ولا Recovery Concept.

## 5. Rejection
Rejection تميز العملية المرفوضة عن غير المكتملة أو المعلقة.
**Rejected ≠ Pending.**
**Rejected ≠ Failed** بالضرورة؛ معنى الحالة يحدده Owner Domain.

## 6. Duplicate operation
التكرار يعني أن محاولة جديدة قد تمثل نفس العملية أو الأثر المقصود.
إعادة المحاولة لا تعني تلقائياً إنشاء أثر دوميني جديد. قد تُكتشف كمتكررة، أو تستمر عملية معلقة، أو تُقبل كعملية مستقلة إذا قرر Owner Domain ذلك.
لا تحدد المواصفة آلية الكشف التقنية.

## 7. Cancel
الإلغاء تغيير دلالي يمنع استمرار عملية وفق شروط المجال.
**Cancel ≠ Delete History.**
الإلغاء لا يعني بالضرورة عكس أثر مالي سابق؛ reversal/refund سلوك منفصل يقرره المجال.

## 8. Refund / Reversal boundary
Refund وReversal حدود دلالية فقط وليسا Concepts جديدة.
Payment/Settlement معناهما التشغيلي لدى Payments.
Financial Transaction/Ledger Entry والأثر النهائي لدى Finance.
Sale/Invoice/Obligation لدى Commerce/Financial Relations.
الإرجاع أو العكس لا يعيد كتابة الأصل وكأنه لم يحدث.

## 9. Recovery boundary
Recovery تعني معالجة حالة استثنائية أو معلقة للعودة إلى حالة مجال قابلة للحسم، وقد تشمل متابعة Pending أو معالجة فقدان جهاز أو مراجعة تعارض.
لا تنشئ Recovery Concept.
الحالة النهائية يقررها Owner Domain.

| Sale/Invoice | Commerce |

| Pending Operation | تشغيلي وليس Domain Truth |

الاستثناء العابر للمجالات لا ينقل الملكية.

## 11. Pending Operation وAgent Action
**Pending Operation ≠ Domain Truth.**
**Agent Action ≠ Domain Truth.**
Agent لا يقرر وحده أن الرفض أصبح قبولاً أو أن الإلغاء أصبح أثراً نهائياً؛ يعمل ضمن Authorization والحقيقة تعود إلى Owner Domain.

## 12. Failure / History / Privacy
- Rejected ≠ Pending.
- Duplicate ≠ New Truth automatically.
- Cancel ≠ Delete History.
- Refund/Reversal ≠ rewriting original history.
- Recovery ≠ new Domain.
- Pending ≠ Finality.
- Local success ≠ Owner Domain acceptance.
- Agent Action failed ≠ Domain Truth.
Provenance/Audit/Domain History تبقى منفصلة.
الإلغاء والإرجاع وإعادة المحاولة قد تتطلب Authorization؛ Family Relationship/Role Assignment ليست Authorization.

## 13. Offline / Conflict
Offline لا يمنح finality.
Conflict لا يصبح Truth ثالثة.
عند التعارض، Owner Domain يحسم الحالة.
لا Sync/Conflict أو reconciliation algorithm.
