# ملف النشاط التجاري — Android وSupabase

**آخر تحديث:** 2026-10-23  
**مرجع التنفيذ:** [PR #527](https://github.com/adnanalhasani2020/Adnanalhasani-/pull/527) و[PR #528](https://github.com/adnanalhasani2020/Adnanalhasani-/pull/528).

## النطاق المنفذ

- تسجيل الدخول وإنشاء الحساب من شاشة ملف النشاط عبر Supabase Auth.
- إرسال بيانات الملف إلى RPC `commercial_create_activity_profile` من شاشة Android باستخدام جلسة المستخدم.
- إدخال بيانات النشاط والمالك والعنوان والبيانات التعريفية.
- إدخال روابط HTTPS خارجية للشعار والغلاف وصور هوية المالك.
- تحقق قاعدة البيانات من هوية المستخدم وتنفيذ إنشاء الملف بصورة ذرية.

## سياسة الصور: الرابط فقط

لا يرفع تطبيق Android أو واجهة الويب ملفات الصور إلى Supabase Storage. حقول الصور روابط خارجية، وتُحفظ الروابط فقط.

حقول RPC ذات الصلة:
- `p_logo_url`
- `p_cover_image_url`
- `p_owner_identity_front_url`
- `p_owner_identity_back_url`

يجب أن تكون الروابط اختيارية عند عدم توفر الصورة، وأن تستخدم HTTPS. يتحقق التطبيق من شكل الرابط، كما تفرض قاعدة البيانات تحققًا على الروابط وفق الترحيل المعني.

## بيانات الهوية والخصوصية

صور الهوية الشخصية حساسة. لا تستخدم روابطًا عامة دائمة أو مستودع صور عامًا لهذه الملفات. استخدم استضافة خاصة مع صلاحيات وصول واضحة، أو روابطًا موقعة قصيرة الصلاحية، وراجع من يستطيع قراءة البيانات الوصفية التي تحتوي الروابط. لا تضع مفاتيح خدمة سرية في التطبيق.

## ترحيل قاعدة البيانات

الترحيل المخصص هو:

`supabase/migrations/20261023203000_commercial_profile_external_image_urls.sql`

يعيد تعريف RPC لقبول روابط الصور الخارجية ويزيل سياسات الرفع القديمة ذات الصلة. بقيت حاويات Storage القديمة موجودة وفارغة بعد التغيير بسبب حماية Supabase من حذفها عبر SQL؛ لا يعني ذلك أن التطبيق ما زال يرفع إليها. لا تصف الحاويات بأنها محذوفة.

## ما لا يشمله هذا الربط

- لا ينشئ الملف منتجات أو مخزونًا.
- لا يربط المبيعات أو الفواتير أو العملاء أو التسديدات أو المصروفات بالسحابة.
- لا ينفذ مزامنة بين الأجهزة أو نسخًا احتياطيًا لبيانات التطبيق المحلية.
- لا يمثل تكامل دفع مصرفيًا أو محفظة أو بوابة دفع.
