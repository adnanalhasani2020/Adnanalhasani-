# بوابة قبول إعدادات المدير

**الحالة:** قائمة تحقق للمراجعة اليدوية، وليست اعتمادًا تشغيليًا.  
**النطاق:** `docs/prototypes/admin-decision-settings.html`  
**القاعدة:** الاختيارات المعروضة لا تصبح سياسات نافذة بمجرد حفظها أو معاينتها.

## 1. التحقق الوظيفي

- [ ] يظهر النموذج بالعربية وباتجاه RTL على الهاتف والحاسوب.
- [ ] لا يمكن إنشاء معاينة قبل اختيار النشاط الرئيسي.
- [ ] تعرض المعاينة اسم النشاط والخيارات المختارة بوضوح.
- [ ] تظهر التوصية الإرشادية مباشرة عند تغيير النشاط، قبل إنشاء المعاينة.
- [ ] تتغير التوصية عند اختيار نشاط آخر، وتبقى موسومة بأنها غير ملزمة ولا تفعّل سياسة.
- [ ] عند استعادة اختيار محفوظ محليًا، تطابق التوصية النشاط المستعاد.
- [ ] يخفي إعادة الضبط التوصية المباشرة ويمسح نصها، إضافة إلى إخفاء المعاينة.
- [ ] لا يؤدي اختيار نشاط صحي إلى تفعيل وظائف الطبيب أو المختبر أو الدواء.
- [ ] لا يؤدي اختيار مراجعة مالية إلى تغيير قواعد العملات أو التسوية أو القيود.
- [ ] يعيد زر إعادة الضبط الحقول إلى القيم الافتراضية ويخفي المعاينة.

## 2. الخصوصية والتخزين

- [ ] يوضح النموذج أن الحفظ محلي في المتصفح ولا يصل إلى الخادم.
- [ ] لا تُدخل بيانات مرضى أو كلمات مرور أو معلومات شخصية حساسة أثناء الاختبار.
- [ ] لا تُستخدم بيانات اختبار حقيقية على جهاز مشترك.
- [ ] اختبر الحفظ والاستعادة عند توفر التخزين المحلي.
- [ ] اختبر فشل الحفظ والاستعادة والحذف، وتأكد من ظهور رسالة مفهومة بدل تعطل النموذج.
- [ ] بعد إعادة الضبط، تحقق من حذف النسخة المحلية؛ إذا فشل الحذف يجب إبلاغ المستخدم صراحةً.

## 3. الإتاحة والأمان

- [ ] لكل حقل تسمية مرئية مرتبطة به.
- [ ] يمكن إكمال النموذج بلوحة المفاتيح فقط.
- [ ] مؤشر التركيز واضح ولا يعتمد على اللون وحده.
- [ ] تصل رسائل الحالة والأخطاء إلى قارئ الشاشة.
- [ ] يحترم النموذج تفضيل تقليل الحركة.
- [ ] تُعرض مدخلات المستخدم كنص عادي، لا كـ HTML قابل للتنفيذ.
- [ ] تُرفض القيم المستعادة غير المعروفة، وتُقص النصوص إلى حدود الحقول.

## 4. بوابة الاعتماد البشري قبل الإنتاج

لا يُنقل النموذج إلى إعدادات إنتاجية قبل استيفاء جميع البنود التالية:

- [ ] تحديد صاحب القرار وصلاحياته والتحقق من هويته.
- [ ] تحديد نموذج بيانات خلفي وواجهة API موثقة، مع تحقق خادمي من جميع القيم.
- [ ] وضع سجل تدقيق غير قابل للتلاعب يوضح من غيّر ماذا ومتى، وما الذي اعتُمد.
- [ ] تحديد سياسة الموافقة والتراجع عن التغييرات الحساسة.
- [ ] اعتماد نطاق الوظائف الصحية والمالية في قرارات المشروع ومواصفاته الرسمية.
- [ ] إضافة اختبارات صلاحيات وتزامن واستمرارية وفشل، واختبارات تكامل على بيئة غير إنتاجية.
- [ ] إجراء مراجعة أمنية وخصوصية وإتاحة قبل الإطلاق.
