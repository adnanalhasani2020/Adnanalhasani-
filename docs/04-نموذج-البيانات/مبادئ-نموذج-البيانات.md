# مبادئ نموذج البيانات

**الحالة:** قرار — **المعرف:** DOC-DATA-0001

هذه مبادئ مجال وليست مخطط جداول نهائياً.

- الهوية ليست الحساب المالي.
- المستخدم ليس النشاط.
- النشاط ليس الموظف.
- الموظف ليس المالك.
- المنتج ليس المخزون.
- الفاتورة ليست المعاملة المالية.
- الرصيد ليس بديلاً عن سجل المعاملات.
- الحساب العائلي ليس مشاركة كلمة مرور.
- الوكيل ليس مستخدماً بصلاحيات مطلقة.
- الذكاء الاصطناعي ليس مصدراً للحقيقة.
- البيانات الصحية ليست بيانات تجارية عادية.
- البيانات المالية تحتاج تدقيقاً خاصاً.
- الأنظمة المحلية لا تعتمد على اتصال دائم دون دراسة.
- واجهات الاستخدام المختلفة تعتمد على منطق المجال والصلاحيات نفسه.

لا تُنشأ الجداول النهائية قبل اكتمال دراسة المجال والمتطلبات والمعمارية والمزامنة والأمن والتدقيق والصحة والمال بحسب انطباقها.

SQLite تخزين محلي مستهدف للدراسة والمرحلة الأولى، وليست التزاماً نهائياً.
