# حالات الفشل والاستثناءات

| الحالة | ما قد يحدث | الأثر المفاهيمي | ما يجب معرفته قبل القرار |
|---|---|---|---|
| انقطاع الإنترنت | العملية لا تصل للطرف الآخر | حالة معلقة/محلية محتملة | هل العملية مسموحة دون اتصال؟ |
| انقطاع الكهرباء | الجهاز يتوقف أثناء العملية | احتمال عدم اكتمال | ما نقطة اعتبار العملية؟ |
| نفاد المخزون | العرض قديم | فشل البيع | كيف يثبت التوفر؟ |
| اختلاف السعر | السعر المتوقع يختلف | نزاع تجاري | من مصدر السعر؟ |
| اختلاف البيانات | جهازان يعرضان حالتين | تعارض | من يملك الحسم؟ |
| رفض العملية | شروط أو صلاحية ناقصة | لا أثر نهائي | هل يسجل سبب الرفض؟ |
| خطأ الموظف | إدخال/اختيار خاطئ | أثر تجاري أو مالي | من يصحح ويعتمد؟ |
| تكرار العملية | إعادة المحاولة تنتج أثراً ثانياً | ازدواج | كيف يميز التكرار؟ |
| تكرار الدفع | دفع مسجل مرتين | خطر مالي | كيف تتم المطابقة والاسترداد؟ |
| الإلغاء | إلغاء قبل/بعد الأثر | تغير حالة | ما الذي يمكن عكسه؟ |
| الإرجاع | سلعة تعاد | تغير مخزون/قيمة | هل يسترد المال؟ |
| استرجاع المبلغ | رد قيمة للعميل | حركة مالية مستقلة | ما المرجع والدليل؟ |
| اختلاف جهازين | عمليات متزامنة | تعارض | ما قاعدة الحسم؟ |
| فقدان الجهاز | وصول أو عمليات معلقة | خطر أمني | كيف توقف الصلاحية؟ |
| تغيير الصلاحيات | الدور يتغير | تغير القدرة | ماذا يحدث للعملية الجارية؟ |
| سحب التفويض | المفوض له يفقد الصلاحية | منع المستقبل | مصير العملية الجارية؟ |
| تضارب طبي | نتائج مختلفة | خطر سريري | من يراجع؟ |
| خطأ صحي | بيانات صحية غير صحيحة | قرار رعاية خاطئ | كيف يصحح دون محو التاريخ؟ |
| تنفيذ وكيل غير مسموح | سوء فهم/تجاوز | أثر غير مصرح | رفض/إيقاف/تدقيق |
| مالية دون شروط | محاولة ناقصة | خطر مالي وتنظيمي | ما الشروط الإلزامية؟ |
| توقف نشاط | الطرف لم يعد متاحاً | التزامات مستمرة | كيف تحفظ الحقوق؟ |
| انقطاع مصدر خارجي | الخدمة الخارجية غير متاحة | عملية غير مكتملة | ما البديل والحالة؟ |

## مبدأ
الفشل ليس دائماً خطأ تقنياً؛ قد يكون رفضاً مشروعاً، أو تعارضاً، أو حالة معلقة، أو نزاعاً يحتاج حسم طرف مسؤول. لا تختزل الاستثناءات إلى «إعادة المحاولة».
