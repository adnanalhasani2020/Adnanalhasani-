# قاموس المجال

## الهوية والوصول
- **المستخدم (User):** الشخص الذي يتعامل مع النظام.
- **الهوية الرئيسية (Primary Identity):** تمثيل الهوية المستمرة للشخص/الجهة.
- **وسيلة الوصول/حساب الوصول (Access Credential/Account):** مفهوم للوصول مرتبط بالمستخدم/الهوية؛ لا يساوي الهوية.
- **الحساب الرئيسي (Primary Account):** مصطلح غير محسوم؛ لا نثبته كهوية ولا كحساب مالي. Q-0001.
- **المصادقة (Authentication):** إثبات الارتباط بهوية/مشترك معروف؛ ليست تفويضاً.
- **التفويض (Authorization):** تحديد ما يجوز فعله.
- **التفويض بالنيابة (Delegation):** منح طرف صلاحية محددة لتنفيذ فعل نيابة عن طرف آخر.
- **الجلسة (Session):** سياق وصول مؤقت.

## النشاط والعمل
- **النشاط (Business/Organization):** جهة تقدم سلعة/خدمة أو تمارس نشاطاً مؤسسياً.
- **علاقة المستخدم بالنشاط (User-Activity Relationship):** علاقة ملكية أو إدارة أو عمل أو عميل أو دور آخر؛ لا تنشئ هوية بشرية جديدة.
- **المالك (Owner):** صاحب علاقة ملكية؛ لا يساوي المدير.
- **المدير (Manager):** مسؤول إدارة؛ قد لا يكون مالكاً.
- **الموظف (Employee):** شخص يعمل لدى نشاط ضمن دور؛ الشخص نفسه يمكن أن يعمل لدى أنشطة متعددة.
- **العميل (Customer):** طرف يتعامل مع النشاط؛ لا يعني تلقائياً وجود دين.

## السلع والخدمات والتجارة
- **المنتج/السلعة العامة (Global Product):** تعريف عام لسلعة يمكن أن تعرضها أنشطة متعددة.
- **الخدمة العامة (Global Service):** تعريف عام لخدمة يمكن أن تقدمها أنشطة متعددة.
- **عرض المنتج (Product Offering):** عرض نشاط لمنتج عام؛ ليس المخزون.
- **عرض الخدمة (Service Offering):** عرض نشاط لخدمة عامة؛ ليس الحجز.
- **المخزون (Inventory):** كمية/حيازة تشغيلية للمنتج لدى نشاط/موقع.
- **موقع/مستودع المخزون (Warehouse/Stock Location):** مكان/نطاق حيازة المخزون.
- **التوفر (Availability):** إمكانية الحصول على منتج/خدمة في سياق وزمن؛ ليس المنتج ولا المخزون.
- **الطلب (Order):** طلب شراء/خدمة قبل أو حول التنفيذ.
- **البيع (Sale):** إتمام عملية تجارية.
- **طريقة بدء العملية/قناة التفاعل (Initiation Channel):** الطريقة التي تبدأ بها العملية؛ ليست العملية نفسها.
- **قناة بدء البيع:** بيع مباشر، باركود، Touch Sale، محادثة، صوت، أو وكيل؛ هذه طرق بدء وليست كيانات بيع.
- **الفاتورة (Invoice):** مستند/سجل تجاري يصف المطالبة أو البيع.
- **السند/القسيمة (Voucher/Instrument):** مفهوم وارد في الرؤية لكن معناه غير محسوم؛ قد يكون خصماً أو ائتماناً أو إذناً أو مطالبة أو قيمة، ولا يجوز تثبيت أحدها دون دليل.
- **المرتجع (Return):** عكس/إرجاع لسلعة أو عملية.
- **الخصم (Discount):** تخفيض للقيمة التجارية.
- **العرض الترويجي (Promotion):** قاعدة/حملة تؤثر في السعر أو الاستحقاق.

## المال والعلاقات بين الأشخاص
- **الحساب المالي (Financial Account):** إطار لعلاقة مالية وحركاتها.
- **الرصيد (Balance):** حالة كمية للحساب/العلاقة عند وقت معين.
- **الدين (Debt):** التزام مستحق بين طرفين.
- **القرض (Loan):** ترتيب لإتاحة قيمة مع التزام بالسداد؛ ليس كل دين قرضاً.
- **الالتزام (Obligation):** واجب مالي/خدمي/تعاقدي؛ ليس كل التزام ديناً.
- **السداد (Repayment/Payment):** وفاء كلي أو جزئي.
- **التسوية (Reconciliation/Settlement):** مطابقة أو إنهاء فروقات/التزامات بحسب السياق.
- **علاقة مستخدم ↔ مستخدم المالية:** قرض أو دين أو التزام أو سداد بين شخصين؛ ليست تلقائياً حساباً تجارياً.
- **المعاملة/الحركة المالية:** حدث مالي له قيمة/اتجاه/سبب/مرجع؛ لا يساوي الفاتورة.

## الصحة
- **المريض (Patient):** متلقي الرعاية.
- **الخدمة الصحية (Health Service):** خدمة رعاية قد تكون مجانية أو مدفوعة.
- **الزيارة (Encounter):** حدث رعاية.
- **الحجز (Appointment):** ترتيب مسبق للخدمة/الزيارة.
- **الفحص (Test/Examination):** إجراء للحصول على معلومات.
- **النتيجة (Result):** مخرج فحص أو خدمة.
- **التقرير (Clinical Report):** سجل يصف نتائج/ملاحظات.
- **التشخيص (Diagnosis):** حكم سريري ضمن سياق الرعاية.
- **الوصفة (Prescription):** توجيه علاجي دوائي.
- **الدواء (Medication):** مادة/علاج دوائي.
- **المتابعة (Follow-up):** نشاط لاحق للرعاية.
- **التذكير (Reminder):** تنبيه متعلق بموعد/علاج/متابعة.
- **التنبيه (Alert):** إشعار بحدث أو خطر محتمل؛ ليس تشخيصاً.
- **المساعدة السريرية (Clinical Decision Support):** دعم لمقدم الرعاية بمعلومات/توصيات؛ لا تساوي طبيباً مستقلاً.
- **التواصل الصحي:** تواصل بين الطبيب والمريض أو المريض والمركز؛ ليس بحد ذاته نتيجة أو قراراً سريرياً.

## الوكلاء والذكاء الاصطناعي
- **الوكيل (Agent):** جهة تنفيذية تعمل نيابة عن صاحب صلاحية ضمن حدود.
- **الذكاء الاصطناعي (AI):** مخرجات تحليلية/اقتراحية؛ ليس مصدر الحقيقة.
- **التوصية:** اقتراح قابل للقبول أو الرفض.
- **الموافقة البشرية:** قرار بشري مطلوب قبل فعل محدد.

## فواصل أساسية
**المستخدم ≠ الهوية الرئيسية ≠ وسيلة الوصول ≠ الجلسة.**
**الحساب الرئيسي ≠ الهوية، ومعناه غير محسوم.**
**المستخدم ≠ علاقة النشاط ≠ الدور.**
**المنتج العام ≠ عرض النشاط ≠ المخزون ≠ التوفر.**
**الحساب المالي ≠ الرصيد ≠ الدين ≠ الحركة المالية.**
**القرض ≠ كل دين، والالتزام ≠ كل دين.**
**الفاتورة ≠ الدفع، والسند/القسيمة ≠ خصم تلقائياً.**
**الخدمة الصحية ≠ الفاتورة، والنتيجة ≠ التشخيص، وAI ≠ طبيب.**
**قناة بدء البيع ≠ البيع نفسه.**
