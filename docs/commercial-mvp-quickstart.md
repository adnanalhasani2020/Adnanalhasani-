# تشغيل النسخة التجارية الأولى محلياً

هذه الواجهة العربية تسمح بإنشاء حساب أو تسجيل الدخول، وعرض العروض التي يثبت النظام أن مخزونها موجب وسعرها نافذ، وتنفيذ البيع، ثم مراجعة الإيصال والمخزون المتبقي.

## تجربة محلية سريعة

يتطلب Python 3.11 أو أحدث. من جذر المستودع:

1. أنشئ قاعدة بيانات تجريبية منفصلة وبيانات دخول مؤقتة:

   ```bash
   PYTHONPATH=src python -m agent_core.commercial_demo_seed \
     --database commercial-demo.sqlite3 --allow-demo-data
   ```

   احتفظ بكلمة المرور التي يطبعها الأمر؛ تظهر مرة واحدة. ينشئ الأمر حساباً تجريبياً ومنتجاً واحداً بسعر SAR ومخزون افتتاحي موثق. يرفض العمل إذا كانت جداول الأشخاص أو الحسابات أو الأنشطة أو المنتجات أو العروض تحتوي بيانات؛ لا تستخدمه على قاعدة بيانات عمل حقيقية.

2. شغّل الواجهة على قاعدة البيانات نفسها:

   ```bash
   PYTHONPATH=src COMMERCIAL_DB_PATH=commercial-demo.sqlite3 \
     python -m agent_core.commercial_web
   ```

3. افتح `http://127.0.0.1:8080`، وسجّل الدخول باستخدام `demo_buyer` وكلمة المرور التي طبعها أمر التهيئة. جرّب شراء كمية، ثم راقب الإيصال والمخزون. عند استهلاك الكمية كلها، يجب أن يختفي العرض من قائمة المنتجات المتاحة.

## حدود مهمة

- هذه نسخة MVP محلية؛ الخادم مربوط بـ loopback افتراضياً. لا تعرضه مباشرة للإنترنت. أي نشر عام يحتاج HTTPS عبر reverse proxy مضبوطاً، وضبط `COMMERCIAL_COOKIE_SECURE=1`، ومراجعة أمنية وتشغيلية إضافية.
- أداة التهيئة مخصصة لقاعدة بيانات تجريبية فارغة فقط. لا تستخدم بيانات دخول التجربة في بيئة عمل.
- المنتجات والأسعار والمخزون في المتجر تُقرأ من السجلات الفعلية؛ لا يُفترض توفر المنتج إذا كان المخزون مجهولاً أو صفراً.
- البيع يثبت عملية البيع وخصم المخزون وإيصالها ضمن معاملة واحدة. لا يعني ذلك تحصيل أموال أو إنشاء قيد مالي تلقائي، ولا يتضمن تكاملاً مع بوابة دفع.
- لا توجد بعد واجهة إدارة متجر آمنة لإضافة المنتجات والأسعار والمخزون الحقيقي؛ لا ينبغي منح كل مستخدم مسجّل صلاحيات إدارة المخزون. هذه هي الفجوة التالية قبل تشغيل متجر حقيقي.
