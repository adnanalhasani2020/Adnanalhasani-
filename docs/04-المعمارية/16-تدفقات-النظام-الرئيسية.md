# تدفقات النظام الرئيسية

1. Access: Identity → Access → Context → Authorization → Operation → Audit.
2. Commerce: Discovery/Channel → Offering → Commercial Operation → Invoice → Payment/Settlement عند الحاجة.
3. Finance: Obligation/Debt → Payment → Settlement → Ledger/Balance وفق قواعد المجال.
4. Health: Access/Delegation → Health Service → Result/Report → Human Clinical Decision؛ AI recommendation لا تستبدله.
5. Agent: Observation → Retrieval → Recommendation → Preparation → Approval إن لزم → Execution → Audit.
6. Offline: Local Context → Allowed Operation → Pending/Local State → Reconciliation/Decision؛ لا نهائية ضمنية.
7. Conflict: Detect → Preserve evidence → Apply source-of-truth rule عندما يكون مقرراً، وإلا يبقى التعارض غير محسوم.
