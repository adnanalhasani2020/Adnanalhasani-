# معمارية التواصل

## المسؤولية والحدود
**Communication** يملك الرسائل والمحادثات والإشعارات وحالة التسليم/المعالجة عندما تكون ضمن نطاق التواصل.

داخل المجال: رسالة، محادثة، إشعار، سياق الإرسال، وحالة التواصل.  
خارجه: لا يملك Communication حقيقة البيع أو الدفع أو الصحة أو الصلاحية.

## الحقيقة والتغيير
مالك الحقيقة: Communication.  
القراء: المستخدمون والمجالات التي تحتاج التواصل وفق Authorization.  
طلب التغيير: صاحب الرسالة/الدور المصرح أو المجال الذي يطلب إخطاراً.  
تغير الحالة: إنشاء الرسالة، إرسالها، استلامها/معالجتها وفق ما يثبته المجال، إلغاء/انتهاء الإشعار.

## Invariants
- Message ≠ Transaction.
- Notification ≠ Domain State Change.
- Chat ≠ Permission.
- إرسال إشعار عن Payment لا يثبت Payment.
- رسالة عن Health لا تجعل Communication مالكاً للسجل الصحي.

## العلاقات
Commerce/Finance/Health/Education/Agents تنتج أحداثاً أو حالات تحتاج إخطاراً؛ Communication يعكسها للمستهلكين دون امتلاك حقيقتها. Channel قد يكون وسيلة بدء، لكنه لا يصبح مالكاً للمحادثة لمجرد أنه قناة تفاعل.
