# حدود المجالات

| المجال | المسؤولية | لا يملك |
|---|---|---|
| Identity & Access | الهوية والوصول والتفويض | الحقيقة المالية/السريرية تلقائياً |
| Activities & Roles | النشاط والأدوار وعلاقة الموظف | الهوية البشرية |
| Commerce | المنتج والعرض والبيع والفاتورة | الرصيد والتسوية |
| Inventory | المخزون وموقعه وحالته | التوفر كحقيقة مستقلة |
| Financial Relations | الحساب والالتزام والدين والقرض | إثبات الدفع الخارجي |
| Payments & Settlement | الدفع والتسوية والتحويلات | السجل الصحي |
| Health | السجل والخدمات والنتائج | السجل التجاري |
| Education | الخدمات والتسجيل والحضور | الصلاحية الأسرية المطلقة |
| Family & Delegation | العلاقات الأسرية والتفويض | الحقيقة السريرية/المالية |
| Communication | الرسائل والإشعارات | تغيير المعاملة |
| Discovery | القرب والتوفر المحلي | إنشاء مخزون/بيع |
| Channels | بدء التفاعل | الأثر المالي |
| Agents & AI | دورة الوكيل المنضبطة | ملكية الحقيقة الأصلية |
| Offline/Multi-device | الحالة المحلية والتعارض والاستعادة | النهائية من تلقاء نفسه |
| Privacy/Security/Audit | القيود الرقابية والأثر | حقيقة المجال |

هذه حدود مسؤوليات مفاهيمية وليست خدمات تقنية مستقلة.
