# السياقات والحدود

السياقات المفاهيمية منفصلة: Identity، Access، Activities، Commerce، Inventory، Financial، Payments، Health، Education، Family، Communication، Discovery، Channels، Agents، Operational، Governance.

المرجع بين مجالين لا ينقل ملكية الحقيقة. الرسالة ليست معاملة، والعرض ليس مخزوناً، والتوفر ليس مخزوناً، والعلاقة الأسرية ليست تفويضاً.
