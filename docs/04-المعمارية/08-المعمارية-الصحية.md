# المعمارية الصحية

Health Context مستقل عن التجارة والمال. السجل والخدمة والزيارة والنتيجة والتقرير والوصفة مفاهيم صحية مترابطة.

الارتباط المالي بالخدمة مرجع بين سياقين، وليس دمجاً للسجل الصحي.

AI ليس صاحب القرار الطبي النهائي. القرار السريري البشري ومسؤوليته منفصلان.

DEC-0001 وDEC-0007 وDEC-0010 تبقى مؤثرة ومفتوحة.
