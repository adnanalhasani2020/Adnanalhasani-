# الخصوصية والأمان والتدقيق

الوصول وفق السياق والسلطة والغرض، مع أقل صلاحية لازمة.

الهوية والصحة والمال والتفويض حدود حساسة. الأفعال الحساسة والمالية والصحية وأفعال التفويض والوكيل قابلة للتدقيق. التصحيح لا يمحو حقيقة وقوع التغيير.

سجل التدقيق يثبت الأثر الرقابي ولا يصبح بديلاً عن حقيقة المجال. لا تصنيف قانوني عالمي مفترض قبل DEC-0001.
