# القنوات والوكلاء

## القنوات
**Channel** يملك سياق بدء التفاعل، لا حقيقة العملية التي بدأت عبره. داخله قناة البدء وسياق الطلب وتمييز مصدر البدء؛ خارجه Sale وPayment وAuthorization وHealth Record.

مالك الحقيقة للقناة: Channel. يقرأ منه Commerce/Communication/Agents. طلب التغيير يأتي من صاحب القناة أو الدور المخول. تغير الحالة يحدث ببدء/استمرار/إغلاق سياق التفاعل.

**Invariant:** Channel ≠ Sale وChannel ≠ Payment.

## الوكلاء
Agent ليس User ولا Domain Owner. سلطته مشتقة من Authorization وحدود السياق.

| المرحلة | طبيعة الفعل | هل يغير حقيقة المجال؟ | الموافقة البشرية |
|---|---|---:|---|
| Observation | معلوماتي | لا | لا ما لم يفرض السياق |
| Retrieval | معلوماتي | لا | لا |
| Recommendation | اقتراحي | لا | لا تعني الموافقة على التنفيذ |
| Preparation | تجهيز قابل للمراجعة | لا | مطلوبة قبل الأفعال الحساسة عند انطباقها |
| Execution | تنفيذي | نعم إذا كان مصرحاً | حسب الصلاحية والقرار |
| Approval/Review | حوكمي | قد يغير أهلية التنفيذ أو يراجع النتيجة | نعم عندما تكون مطلوبة |

Agent يملك حقيقة فعله ونتيجته التشغيلية ضمن سياق الوكيل، لكن المجال المستهدف يملك الحقيقة بعد التنفيذ. Authorization يملك حدود السلطة.

**Invariants:** Agent ≠ User، Agent ≠ Domain Owner، Recommendation ≠ Decision، Preparation ≠ Execution، automation لا تنشئ authority، والوكيل الصحي لا يكون صاحب القرار السريري النهائي.

**القرارات المفتوحة:** DEC-0006 حدود الوكيل المالي، DEC-0007 حدود الوكيل الصحي، DEC-0008 القنوات المدعومة، DEC-0001 الولاية. لا نفترض أياً منها.
