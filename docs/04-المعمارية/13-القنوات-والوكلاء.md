# القنوات والوكلاء

القناة طريقة بدء التفاعل وليست Transaction أو Payment.

دورة الوكيل: Observation → Retrieval → Recommendation → Preparation → Execution → Approval/Review.

Agent ≠ User. لا صلاحية لمجرد وجود automation. الأفعال التي تتطلب موافقة لا تنفذ دون موافقة بشرية.

DEC-0006 وDEC-0007 وDEC-0008 مفتوحة. لا اختيار AI provider.
