# العمل دون اتصال وتعدد الأجهزة

Offline حالة تشغيلية وليست مالكاً مستقلاً لحقيقة المجال.

## التصنيف
| التصنيف | أمثلة مفاهيمية | سبب التصنيف |
|---|---|---|
| Offline-safe | قراءة معلومات معتمدة، إعداد مسودة | لا يحتاج حقيقة خارجية متغيرة لحظة الفعل |
| Offline-possible-with-constraints | تسجيل طلب أو تجهيز عملية معلقة | يمكن قبولها بشرط عدم ادعاء النهائية |
| Online-required | تحقق حساس من الصلاحية أو حسم يحتاج المصدر المباشر | لا يجوز افتراض النتيجة محلياً |
| Decision-dependent | Offline المالي، حسم تعارض المخزون/الجهاز، أثر فقدان الجهاز | مرتبط بـ DEC-0011/0012/0013 |

**Offline Operation ≠ Finality.** و **Offline possible ≠ Offline suitable.**

## تعدد الأجهزة والتعارض
المعمارية لا تختار خوارزمية حل التعارض. الثوابت هي:
1. إثبات وقوع التعارض.
2. عدم اعتبار النسخة المحلية مصدراً للحقيقة.
3. عدم اختيار الفائز تلقائياً من ترتيب الأجهزة.
4. استخدام قاعدة حسم يملكها المجال عندما تكون مقررة.
5. إبقاء الحالة غير محسومة عندما لا توجد قاعدة معتمدة.

مالك الحقيقة يبقى المجال الأصلي؛ الجهاز يحمل حالة تشغيلية محلية فقط.
