# البيانات والملكية ومصادر الحقيقة

| المفهوم | مصدر الحقيقة المفاهيمي | لا يجوز استنتاجه |
|---|---|---|
| Human Identity | Identity | صلاحية |
| Access Account | Access | هوية بشرية |
| Financial Account | Financial | Balance |
| Obligation/Debt | Financial Relations | Payment |
| Ledger | Financial | Balance فقط |
| Balance | Financial كقيمة مشتقة | مصدر أثر مستقل |
| Payment | Payments | Settlement نهائي |
| Settlement | Payments | Invoice |
| Inventory | Inventory | Availability مطلق |
| Availability | Discovery | مخزون مؤكد |
| Health Record | Health | Commercial Record |
| Delegation | Family/Authorization | Family Relationship |
| Agent Authority | Authorization/Agent | صلاحية مستقلة |
| Audit Record | Governance | بديل لحقيقة المجال |

كل مفهوم حساس له مالك دلالي واحد. القرارات المفتوحة قد تغير التفاصيل دون إنشاء مصدر حقيقة ثانٍ بصمت.
