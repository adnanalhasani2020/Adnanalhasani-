# القرارات المطلوبة من صاحب المشروع

**الحالة:** مفتوحة جزئياً — DEC-0001 وDEC-0002 وDEC-0003 وDEC-0004 وDEC-0005 وDEC-0006 وDEC-0007 وDEC-0008 وDEC-0009 وDEC-0010 وDEC-0011 وDEC-0012 وDEC-0013 = **DECIDED / RESOLVED**. لا يعني حسم DEC-0001 اعتماد المتطلبات التابعة أو تغييرها تلقائياً.

## قرارات استراتيجية
| المعرف | القرار المطلوب | الأسئلة المرتبطة | أثره على المتطلبات |
|---|---|---|---|
| DEC-0001 | **اليمن هو الدولة/السوق المرجعي الأول — DECIDED / RESOLVED** | Q-0002,Q-0004,Q-0007,Q-0008,Q-0010,Q-0014,Q-0025,Q-0026,Q-0027,Q-0032 | يحدد القيود القانونية والقطاعية ضمن السوق المرجعي الأول |
| DEC-0002 | **الخيار الثاني — تجميع منطقي غير مالك — DECIDED / RESOLVED** | Q-0001 | يحسم معنى Primary Account كما ورد في الخيار الثاني دون إضافة تفاصيل |
| DEC-0003 | **الخيار 2 — DECIDED / RESOLVED** | Q-0028,Q-0034 | يحدد حدود الدور المالي والمسؤولية دون افتراض دور مؤسسة مالية |
| DEC-0004 | **الخيار 1 — تفويض عائلي واضح ومحدود بالصلاحيات — DECIDED / RESOLVED** | Q-0003,Q-0004,Q-0014 | يحدد الفصل بين العلاقة الأسرية والتفويض والتصريح؛ لا يحسم تفاصيل قانونية أو عمرية غير معتمدة |
| DEC-0005 | **الخيار 1 — Instruments مستقلة قابلة للتتبع — DECIDED / RESOLVED** | Q-0031 | يحدد فصل Instrument عن Invoice/Payment/Settlement/Ledger |
| DEC-0006 | **User-configured Agent Authority — DECIDED / RESOLVED** | Q-0015,Q-0016 | يحدد إطار السلطة مع القيود المعتمدة |
| DEC-0007 | **User Configuration ضمن قيود السلطة — DECIDED / RESOLVED** | Q-0012,Q-0016 | يحدد إطار سلطة AI الصحية مع القيود المعتمدة |
| DEC-0008 | **الخيار 1 — القنوات قنوات لبدء نفس العمليات — DECIDED / RESOLVED** | Q-0033 | يحدد نطاق القنوات دون إنشاء أنظمة بيع مستقلة |
| DEC-0009 | **الخيار 1 — Available Nearby — DECIDED / RESOLVED** | Q-0018,Q-0019 | يحدد معنى التوفر القريب وحداثة بياناته |
| DEC-0010 | **التجارة والخدمات اليومية هي الأولوية الأولى — DECIDED / RESOLVED** | Q-0024 | يحدد أولوية ترتيب المراحل والموارد والـMVP/الإصدارات الأولى، دون إلغاء الصحة أو التعليم أو المال |
| DEC-0011 | **Financial operations require connectivity — DECIDED / RESOLVED** | Q-0007,Q-0020 | يمنع النهائية المالية دون اتصال |
| DEC-0012 | **رفض الحفظ النهائي للمخزون دون اتصال — DECIDED / RESOLVED** | Q-0009,Q-0021 | يحدد حدود Offline Inventory Finality |
| DEC-0013 | **إلغاء العمليات المعلقة عند فقد الجهاز — DECIDED / RESOLVED** | Q-0022 | يحدد أثر فقد الجهاز دون حذف النهائيات أو التاريخ |

## قواعد
- هذه القائمة توثق أن **DEC-0001..DEC-0013 جميعها DECIDED / RESOLVED** بعد دفعة القرارات الحالية.
- لا تستخدم «معتمد» في المتطلبات التابعة لمجرد حسم DEC-0001؛ يلزم إجراء مراجعة أثر وتحديث التتبع قبل أي اعتماد أو تنفيذ.
- الولاية المرجعية لـDEC-0001 محددة الآن: **اليمن**. هذا لا يحصر التوسع الجغرافي المستقبلي.
- المسائل التقنية Q-0009/Q-0020/Q-0021/Q-0022 تحتاج بحثاً تقنياً لاحقاً عند فتح مرحلته.
