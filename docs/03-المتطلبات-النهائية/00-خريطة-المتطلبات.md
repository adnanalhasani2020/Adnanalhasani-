# خريطة المتطلبات

## الحالة
مرحلة المتطلبات مفتوحة وقيد التنفيذ. هذه الوثائق تحول مخرجات فهم المجال والبحث والأدلة إلى متطلبات قابلة للتتبع والمراجعة والاختبار لاحقاً. لا تمثل مواصفات تقنية.

## قواعد التصنيف
- **معتمد:** لا يستخدم إلا لمطلب اعتمد صراحة.
- **مقترح:** صياغة مرشحة مبنية على مصدر/دليل ولم تعتمد نهائياً.
- **يحتاج قراراً:** لا يمكن تثبيته قبل قرار صاحب المشروع.
- **مسودة:** صياغة أولية تحتاج مراجعة.
- **مستبعد/مستبدل:** عند وجود سبب موثق.

## نطاق التتبع
المصدر → سؤال/خطر → دليل/نتيجة → قيد/قرار → المتطلب → تحقق مستقبلي.

## مبادئ مانعة للتجاوز
- لا يتحول الدليل إلى قرار تلقائياً.
- لا تتحول التوصية إلى متطلب معتمد تلقائياً.
- لا تخمن الولاية القضائية.
- لا يحسم هذا الملف Primary Account أو دور النظام المالي أو voucher أو حدود الوكيل.
- لا تبدأ المعمارية أو نموذج البيانات أو التنفيذ من هذه الوثائق.
