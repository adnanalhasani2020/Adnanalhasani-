# تطبيق المستشفى الأصلي لنظام Android

هذا مشروع Android مستقل بواجهة عربية RTL وتصميم Material 3، أُضيف إلى المستودع في المسار `android-hospital/` دون حذف أو استبدال واجهات الويب الحالية.

## الواجهات الموجودة

- لوحة التحكم ومؤشرات محلية.
- المرضى.
- الأطباء.
- المواعيد.
- الزيارات الطبية.
- المختبر.
- الصيدلية والأدوية.
- التنويم والأسرة.
- الفواتير.
- المدفوعات.
- الوصفات الطبية.
- المستخدمون (سجل إداري محلي، وليس نظام مصادقة).
- التقارير والمؤشرات.
- الإعدادات.
- قائمة موحدة لجميع الأقسام.

كل قسم يحتوي نموذج إدخال وسجلًا محفوظًا محليًا، مع إمكانية حذف السجل.

## التقنيات المجانية المستخدمة

- Kotlin وJetpack Compose.
- Material 3 وMaterial Icons Extended.
- Navigation-ready screen architecture.
- Room فوق SQLite.
- Kotlin Coroutines وFlow.

## البناء والتشغيل

1. افتح مجلد `android-hospital` في Android Studio حديث.
2. استخدم JDK 17 وثبّت Android SDK 35.
3. نفّذ Gradle Sync.
4. شغّل التطبيق على محاكي أو جهاز Android (minSdk 26).

## حدود مهمة قبل الإنتاج

هذه نسخة تأسيسية أولية وليست إصدارًا إنتاجيًا مكتملًا. تستخدم قاعدة Room محلية باسم `hospital-local.db` وجدول سجلات عام لتخزين إدخالات الأقسام؛ لم تُنفذ بعد جداول علائقية مستقلة لكل كيان أو قواعد الربط والتحقق السريرية والمالية كاملة.

قاعدة SQLite في Android مستقلة عن ملف SQLite الذي يستخدمه خادم Python. لا يمكن لتطبيق الهاتف الاتصال مباشرة بملف قاعدة بيانات موجود على خادم آخر؛ يتطلب ذلك API ومزامنة آمنة، وهو غير منفذ في هذه النسخة. لم تُنقل أي بيانات قائمة ولم يُعدّل مخطط قاعدة المستشفى الحالي.

لم يُرفق APK مبني أو نتيجة بناء CI مع هذا التغيير؛ يجب فتح المشروع وبناؤه واختبار جميع الشاشات قبل اعتباره جاهزًا. لا تستخدم بيانات مرضى حقيقية في هذه النسخة، ولا تعرضها كمنظومة سريرية معتمدة.
