# تطبيق المستشفى الأصلي لنظام Android

هذا مشروع Android مستقل بواجهة عربية RTL وتصميم Material 3، أُضيف إلى المستودع في المسار `android-hospital/` دون حذف أو استبدال واجهات الويب الحالية.

## الواجهات الموجودة

- لوحة التحكم ومؤشرات محلية.
- المرضى.
- الأطباء.
- المواعيد.
- الزيارات الطبية.
- المختبر.
- الصيدلية والأدوية.
- التنويم والأسرة.
- الفواتير.
- المدفوعات.
- الوصفات الطبية.
- المستخدمون (سجل إداري محلي، وليس نظام مصادقة).
- التمريض والعلامات الحيوية.
- الأشعة والتصوير.
- العمليات والإجراءات الطبية.
- المخزون الطبي.
- الموردون والمشتريات.
- المصروفات والصندوق.
- التأمين الطبي والمطالبات.
- الموظفون والدوام.
- الأقسام والتخصصات.
- المرفقات والوثائق (فهرسة فقط، لا رفع ملفات بعد).
- سجل العمليات (إدخال يدوي، لا يسجل أحداث النظام تلقائيًا بعد).
- التقارير والمؤشرات.
- الإعدادات.
- قائمة موحدة لجميع الأقسام، مع بحث فوري باسم القسم أو وصفه وحالة واضحة عند عدم وجود نتائج.

كل قسم يحتوي نموذج إدخال وسجلًا محفوظًا محليًا، مع إمكانية حذف السجل. المرضى والأطباء والمواعيد والفواتير والمدفوعات تُسجّل كذلك في جداول Room متخصصة، بالإضافة إلى سجل التوافق العام.

## التقنيات المجانية المستخدمة

- Kotlin وJetpack Compose.
- Material 3 وMaterial Icons Extended.
- Navigation-ready screen architecture.
- Room فوق SQLite.
- Kotlin Coroutines وFlow.

## البناء والتشغيل

1. افتح مجلد `android-hospital` في Android Studio حديث.
2. استخدم JDK 17 وثبّت Android SDK 35.
3. نفّذ Gradle Sync.
4. شغّل التطبيق على محاكي أو جهاز Android (minSdk 26).
5. يمكن بناء نسخة Debug من مجلد المشروع بالأمر `gradle assembleDebug` بعد تثبيت Gradle وAndroid SDK 35.
6. يوفّر GitHub Actions فحص بناء تلقائياً عند تعديل ملفات `android-hospital/`، ويرفع ملف APK كـ Artifact إذا نجح البناء.

## حدود مهمة قبل الإنتاج

هذه نسخة تأسيسية أولية وليست إصدارًا إنتاجيًا مكتملًا. تستخدم قاعدة Room محلية باسم `hospital-local.db`. الإصدار 2 أضاف جداول متخصصة للمرضى والأطباء والمواعيد والفواتير والمدفوعات، والإصدار 3 أضاف علاقات مفاتيح أجنبية اختيارية بين المواعيد والمرضى والأطباء، وبين الفواتير والمرضى، وبين المدفوعات والفواتير. تشمل القاعدة فهارس للبحث ومفاتيح فريدة لأرقام الملفات والأطباء والفواتير. يحتفظ جدول `hospital_records` القديم بالتوافق وبالسجلات السابقة، وتنفذ ترقيات Room من الإصدار 1 إلى 2 ثم 3، مع ترحيل السجلات الموجودة ومحاولة ربط الأسماء القديمة بالمعرّفات المطابقة دون حذف السجلات. تُسجّل الوحدات الأساسية في الجدول العام والجدول المتخصص ضمن معاملة واحدة، كما تحذف عملية حذف السجل المقابل من الجدول المتخصص ضمن معاملة واحدة. ما زالت بعض الوحدات الأخرى تستخدم الجدول العام. العلاقات الجديدة متاحة في قاعدة البيانات الأساسية، لكن ربط الأسماء بالمعرّفات يعتمد على تطابق الاسم المدخل، ولا توجد بعد واجهات اختيار من قوائم مرضى وأطباء أو مصادقة ومزامنة آمنة.

قاعدة SQLite في Android مستقلة عن ملف SQLite الذي يستخدمه خادم Python. لا يمكن لتطبيق الهاتف الاتصال مباشرة بملف قاعدة بيانات موجود على خادم آخر؛ يتطلب ذلك API ومزامنة آمنة، وهو غير منفذ في هذه النسخة. لم تُنقل أي بيانات قائمة ولم يُعدّل مخطط قاعدة المستشفى الحالي.

لم يتم تأكيد نجاح بناء CI أو إنتاج APK حتى الآن؛ لا تعتبر التطبيق جاهزًا قبل ظهور نجاح مهمة Android build وتنزيل الـ Artifact واختبار جميع الشاشات على جهاز فعلي. لا تستخدم بيانات مرضى حقيقية في هذه النسخة، ولا تعرضها كمنظومة سريرية معتمدة.
